# 정리 D: 평면 Δ = 4, 모든 고정 D3 ∈ (0, 2)에서 NP-완전

상태: **증명 초안**(2026-09-27). 구성은 Choi–Nakajima–Rim(1989) 정리 2를 그대로 쓰고, 비용 계산은 새로 했다. 수치 확인은 `cnr_reduction.py`, `cnr_unsat_test.py`에 있다.

## 정리

**정리 D.** 유리수 D3 ∈ (0, 2)를 고정하면, "최대 차수 4인 평면 그래프 G와 수 K가 주어질 때 OPT_D3(G) ≤ K인가?"는 NP-완전이다.

**따름정리 (Δ = 4의 이분법).** 최대 차수 4 평면 그래프에서 이 문제는 다음과 같이 나뉜다.
- 0 ≤ D3 < 2이면 NP-완전이다. D3 = 0은 평면 3색칠(Garey–Johnson–Stockmeyer)이고, 0 < D3 < 2는 정리 D다.
- D3 ≥ 2 = ⌊4/2⌋이면 다항 시간이다(정리 A).

**따라서 Δ = 4에서 원래 추측은 참이고, 문턱은 정확히 ⌊Δ/2⌋다.** Δ ≥ 4이면 같은 인스턴스로 0 < D3 < 2에서 NP-완전이다. 남은 열린 구간은 Δ ≥ 6에서의 [2, ⌊Δ/2⌋)이다.

## 구성 (Choi, Nakajima, Rim, SRC TR 87-203, pp. 9–12; SIAM J. Discrete Math. 2 (1989))

각 절에 정확히 3개의 리터럴이 있는 Planar 3-SAT(Lichtenstein) 인스턴스 φ(변수 n개, 절 m개)에서 G_φ를 만든다.

- **변수 부품.** 변수 vᵢ가 nᵢ번 나오면 길이 4nᵢ인 사이클 b^{k1} b^{k2} b^{k3} b^{k4}(k = 1…nᵢ)를 만든다. 사이클의 각 변 (b^{kl}, b^{k,l+1}) 위에 꼭짓점 a^{kl}을 얹어 삼각형을 만든다. 따라서 부품마다 삼각형이 4nᵢ개다.
    - b^{k1}, b^{k3}는 vᵢ 형, b^{k2}, b^{k4}는 ¬vᵢ 형이다.
- **절 부품.** 절 c_j마다 w¹…w⁴와 간선 w¹w⁴를 둔다. 리터럴 l(= 1, 2, 3)은 w^l과 w^{l+1}을 한 변수 부품의 이웃한 두 꼭짓점 a, a′에 잇는다.
    - a와 a′은 그 리터럴 형의 b 하나를 공유한다. 양 리터럴은 a^{k2}, a^{k3}(공유 b^{k3})를, 음 리터럴은 a^{k1}, a^{k2}(공유 b^{k2})를 쓴다.
    - 그러면 **절 사이클** w¹ → a → b → a′ → w² → … → w⁴ → w¹의 길이는 13(홀수)이다.
- **크기와 성질.** 정점 28m개, 간선 43m개다. 평면이고 최대 차수는 4다(b는 사이클 2 + 꼭짓점 2).

(주: TR 본문에서 음 리터럴의 꼭짓점 쌍과 참/거짓 삭제 규칙의 서술이 서로 어긋난다. 위는 TR의 예시 절 사이클과 일치하도록 맞춘 판이다. 뜻은 같다.)

**(P) Choi–Nakajima–Rim의 결론.** "G_φ − V′이 이분인 |V′| = 6m인 V′가 존재한다 ⇔ φ가 충족 가능하다."
- 충족 가능할 때의 V′은 **각 변수 부품에서 참인 리터럴 형의 b 전부**다.
- 이 V′은 사이클을 따라 하나 걸러 하나씩이므로 **독립집합**이다.

## 증명

NP 소속은 자명하다. K = 6m·D3로 둔다.

**하한(비용을 삼각형에 나눠 매기기).** 배치 s를 하나 잡는다. 변수 부품의 삼각형 T마다 charge(T)를 다음 두 항의 합으로 정의한다.
- T의 간선 중 같은 상태 결합의 수
- T의 꼭짓점 중 상태 3인 것의 D3 비용을 그 꼭짓점이 속한 삼각형 수로 나눈 몫. b는 삼각형 2개, a는 1개에 속한다.

한 부품 안의 삼각형들은 간선을 공유하지 않는다. 변수 부품끼리는 정점을 공유하지 않는다. 그래서 Σ_T charge(T) ≤ cost(s)이다.

각 T의 charge는 다음과 같다.
- 상태 3이 없으면 T에 같은 상태 결합이 있으므로 charge ≥ 1이다.
- 상태 3 꼭짓점 a가 있으면 charge ≥ D3이다.
- 상태 3이 b뿐이면 charge ≥ D3/2이다.

D3 < 2이므로 **charge(T) ≥ D3/2**이다. 등호는 T에 상태 3이 **밑변 꼭짓점 b 하나뿐**이고 T에 같은 상태 결합이 없을 때만 성립한다. 삼각형 총수는 Σ 4nᵢ = 12m이므로 cost(s) ≥ 12m · D3/2 = 6m·D3이다.

**등호 조건.** cost(s) = 6m·D3이면 다음이 모두 성립한다.
- 모든 삼각형이 등호다.
- 삼각형 밖의 비용이 0이다. 즉 w나 다른 곳에 상태 3이 없고, 같은 상태 결합이 전혀 없다.

그러면 각 부품에서 이웃한 삼각형이 b를 공유하므로, 상태 3인 b는 사이클을 따라 **정확히 하나 걸러 하나**다. 즉 vᵢ 형 전부이거나 ¬vᵢ 형 전부이고, 이것이 vᵢ의 참/거짓을 정한다. 또 s는 진짜(proper) 3색칠이므로 G_φ − S는 이분이다. 따라서 모든 절 사이클(홀수)이 S와 만난다. 절 사이클이 지나는 b는 그 리터럴 형이므로, 각 절에서 참인 리터럴이 하나 이상 있다. 즉 φ는 충족 가능하다.

**충족 가능이면 비용이 6m·D3.** (P)의 V′을 상태 3으로 칠하고 G_φ − V′을 두 색으로 칠한다. V′이 독립이므로 같은 상태 결합이 없다. 비용은 |V′|·D3 = 6m·D3다. ∎

## 확인할 점
- 평면성은 Choi–Nakajima–Rim의 주장에 의존한다("it is clear that G is planar"). 정리 B1 때처럼 직접 확인할 가치가 있다.
    - 다만 이 구성에는 전역 기준 경로가 없다. 절 사이클은 각 절 영역 안에서 세 변수 고리만 지난다. 그래서 Planar 3-SAT의 연결 그래프가 평면이고 변수 고리에서 출현 순서를 회전 순서에 맞추면 평면이 된다.
- 삼각형 나눠 매기기에서 "변수 부품끼리 정점을 공유하지 않는다"는 구성에서 자명하다.
