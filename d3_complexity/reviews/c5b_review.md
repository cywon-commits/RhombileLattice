- 서술이 너무 짧은 곳이 두 군데 있다(보조정리 2의 걷기, 보조정리 4의 "w_j 제외" 표현). 둘 다 몇 줄 덧붙이면 해결된다.

## 보조정리별 검토

### 0. (F1), (F2), 최대 빡빡 집합의 존재 — **검증됨**
- (F1): X의 정점을 하나씩 다시 넣는다. 이미 칠해진 이웃은 3개 이하이므로 소수 쪽 색을 주면 새 좌절은 1개 이하다. 따라서 fr(G) ≤ fr(G−X) + |X|이다. X가 독립일 필요는 없다.
- (F2): k(S) = 0이고 빡빡하면 S는 크기 fr인 독립 OCT다. (F1)에 의해 모든 OCT는 크기 fr 이상이다. 따라서 ioct = fr이다.
- ∅이 빡빡하므로 최대 빡빡 집합이 존재한다. 빡빡한 S는 |S| ≤ fr을 만족하므로 유한하다.
- 연결 가정을 쓴 부분: fr과 ioct는 성분별로 더해진다. 그래서 "K₄ 성분 없음"은 "연결이고 K₄ 아님"으로 줄어든다. **이 환원을 본문에 한 줄 적어야 한다**(현재는 암묵적이다).

### 1. 보조정리 1 (덧붙이기) — **검증됨**
- v ∉ S이고, v는 G−S의 최대 컷에서 좌절 결합의 끝점이다. 그 컷에서 v를 지우면 좌절이 1개 이상 줄어들므로 fr(G−S−v) ≤ k−1이다.
- 따라서 φ(S+v) ≤ fr이고, (F1)에 의해 등호다.
- v가 S와 이웃하지 않으므로 S+v는 독립이다.

### 2. 보조정리 2 (막힌 구조) — **검증됨** (서술 보강 권장)
- uv가 좌절 결합이면 u와 v 둘 다 끝점이다. 보조정리 1과 최대성에 의해 둘 다 S와 이웃하므로 deg_K ≤ 2이다.
- deg_K = 1이면 뒤집어서 컷이 커진다. v₁이 같은 쪽이어도 뒤집어서 컷이 커진다.
- G−S의 최대 컷은 성분별 최대 컷의 합이다. 그래서 K 안에서 뒤집어도 G−S의 최대 컷이 유지되고, 보조정리 1의 가정이 계속 성립한다.
- **걷기 논증의 빠진 부분.** 수열 u, v=v₀, v₁, v₂, …를 생각한다. v_{i+1}은 v_i의 이웃 중 v_{i−1}이 아닌 것이다(v_{−1} = u).
  - 모든 v_i와 u의 K-차수는 2다.
  - 처음으로 되풀이되는 정점 v_m을 보자. v_m = v_i (i ≥ 0)라면 v_{m−1} ∈ {v_{i−1}, v_{i+1}}이어야 한다. 그러면 더 이른 되풀이가 생기거나 되돌아가기(i = m−2)가 된다. 둘 다 불가능하다.
  - 따라서 v_m = u이다. 즉 u, v₀, …, v_{m−1}은 모든 정점의 K-차수가 2인 사이클이고, K가 연결이므로 K 자체다.
  - 본문의 "방문하는 정점이 모두 K-차수 2이므로 K는 사이클"은 이 논증을 줄여 쓴 것이다. 참이지만 위 내용을 적어 두는 것이 좋다.
- 걷기가 사이클 전체를 돈다. 따라서 모든 정점이 어떤 최대 컷에서 좌절 결합의 끝점이고, S-이웃이 1개 이상이다. 차수 제한에 의해 S-이웃은 정확히 1개, 차수는 3이다. ✓

### 3. 보조정리 3 (기본 구조) — **검증됨**
- T′의 독립성: y의 이웃은 t와 사이클 이웃 둘이고, 사이클 이웃은 T에 없다. ✓
- fr(G−T′) ≤ k: t는 T 안에 이웃이 없고(T가 독립) y를 잃는다. 따라서 G−T′에서 t의 이웃은 2개 이하이고, 늘어나는 좌절은 1 이하다. (F1)에 의해 등호다. |T′| = |T|이므로 T′은 **최대** 빡빡 집합이고, 보조정리 2를 T′에 쓸 수 있다. ✓
- t가 다른 홀수 사이클 성분 Y₂와 이웃하는 경우: 합쳐진 성분 D는 Y₂를 포함하므로 좌절이 있다. 그런데 t에 붙은 Y₂의 정점은 D-차수가 3이므로 D는 사이클이 아니다. 보조정리 2에 어긋난다. ✓
- 두 이분 성분을 잇기만 해서 fr(D) = 0이 되는 경우도 막힌다. 그러면 fr(G−T′) = k−1 < k가 되어 (F1)에 어긋난다. 본문의 "(F1)에 의해 = k"가 이 경우를 덮는다. ✓
- D는 홀수 사이클이다. 그래서 D − t는 연결된 경로다. D − t는 t와 이웃하는 G−T−y 성분들의 합집합이므로, 그런 성분은 **정확히 하나**(W)다. ✓
- t의 T′-이웃은 y 하나뿐이므로 deg t = 3이다. 단순 그래프이므로 t₁ ≠ t₂이고 |W| ≥ 2이며 짝수다. ✓
- W = Y−y인 경우: t₁, t₂는 Y−y의 끝점 y⁺, y⁻이다. 같은 논증을 y⁺에 적용하면 t의 나머지 두 이웃 {y, y⁻}은 Y−y⁺의 끝점 {y, y⁺⁺}이어야 한다. 따라서 y⁻ = y⁺⁺이고 |Y| = 3, {t}∪Y는 K₄다. 모든 차수가 3이므로 K₄ 성분이 된다. ✓
- 그 밖의 경우: W는 G−T의 성분 중 Y가 아닌 것(짝수 경로 Q)이다. t의 이웃 t₁, t₂는 Y 밖에 있으므로 (a)가 성립한다. (b), (c)도 성립한다. ✓
- 차수 2 정점: 사이클, t, Q의 정점이 모두 차수 3임을 보조정리 2가 강제한다. 차수 2 정점이 끼어들 여지는 없다. 다중 간선은 단순 그래프이므로 없다. ✓

### 4. 보조정리 4 (사슬 불변식) — **검증됨** (검토 요청 항목 모두 확인)
- **G − T_j의 성분 목록은 맞고 빠진 것이 없다.**
  - T_j = (S − {w₁..w_j}) ∪ {p₁..p_j}이고 G − T_j = (G−S) − P + W이다.
  - 보조정리 3(a),(b)를 단계 i에 쓰면 N(w_i) = {p_i} ∪ {R_i의 두 끝점}이다(deg w_i = 3).
  - p_i ∈ R_{i−1}(또는 Z)이다. 따라서 변하는 G−S 성분은 Z, R₁, …, R_j뿐이다. S가 독립이므로 w들끼리는 이웃하지 않는다.
  - 변한 부분의 성분은 다음과 같다: Z − p₁ (w₁은 Z에서 p₁에만 이웃), R_i − p_{i+1} + w_i (i < j, w_{i+1}은 R_i에서 p_{i+1}에만 이웃), R_j + w_j.
  - (i)형 성분은 p에도 w에도 이웃하지 않는다. 따라서 T_j-이웃 = S-이웃이다. ✓
- **p_i의 이웃.** p_i는 사이클 R_{i−1}+w_{i−1} 위에 있고(i=1이면 Z), 차수 3, T_{i−1}-이웃이 w_i 하나다. 따라서 N(p_i) = (사이클 이웃 2개) ∪ {w_i} ⊆ R_{i−1} ∪ {w_{i−1}, w_i}이다. p_i가 R_{i−1}의 끝점인 경우도 w_{i−1}로 포함된다. r ∈ R_j이고 R_j ≠ R_{i−1}이며 r ∉ S이다. 그러므로 **x는 어떤 p도 아니다.** ✓
- **x ∈ S − W.** T_j ∩ W = ∅이다(w는 빠진 뒤 다시 들어오지 않고, 다시 들어오는 것은 S 밖의 p들뿐이다). 따라서 x가 어떤 w와 같을 수 없다는 것은 자명하다. ✓ 그 결과 w들은 서로 다르고 p들도 서로 다르다(p들은 서로 다른 성분에 있다).
- **회전 경로 배제는 모든 경우를 덮는다.** R′은 경로이므로 (iii)이 아니다. (ii)의 경우는 다음 셋이 전부다.
  - Z − p₁: 두 끝점 z⁺ ≠ z⁻가 있다(|Z| ≥ 3). 각 Z 정점은 S-이웃이 정확히 하나(보조정리 2)이므로 s(z⁺) = s(z⁻) = x가 된다. 보조정리 3의 "서로 다름"에 어긋난다. ✓
  - p_{i+1}이 R_i의 내부 정점: 두 끝점이 모두 R_i에 있다. x ∈ S − W ⊆ T_i이므로 x는 두 끝점 각각의 유일한 T_i-이웃이다. 단계 i의 (T_i, R_i+w_i)에서 보조정리 3의 "서로 다름"에 어긋난다. ✓
  - p_{i+1}이 R_i의 끝점(|R_i| = 2인 삼각형 포함): 끝점 하나가 w_i다. x ∈ S이고 w_i ∈ S인데 S는 독립이므로 **바로 모순이다.** 본문의 "T_j ∩ N(w_i) ⊆ {p_i, p_{i+1}}"도 맞지만, S의 독립성을 쓰는 편이 한 줄로 끝난다. ✓
- **사슬은 이미 지난 성분으로 돌아갈 수 없다.** (I2)가 Z를 포함해 매 단계 새 G−S 성분임을 보장한다. ✓
- (I3)의 귀납 단계: R_{j+1}은 (i)형이므로 S-이웃 = T_j-이웃이다. T_{j+1}-이웃은 T_j-이웃에서 x = w_{j+1}을 뺀 것이다(p_{j+1}은 R_{j+1}과 이웃하지 않는다). x는 R_{j+1}의 두 끝점에만 이웃한다. ✓
- 사소한 표현 문제: "p_{j+1} ∈ R_j … w_j는 제외"에서 w_j ∉ R_j이므로 "제외"는 불필요하다. "사이클 R_j + w_j의 정점 중 w_j가 아닌 것"으로 쓰면 뜻이 분명하다.

### 5. 영역 세기 — **검증됨. 다만 필요 없다.**
- (P3): R = R_j인 사슬을 p_{j+1} = r로 늘린다. (I3)에 의해 r의 S-이웃 중 w_j가 아닌 것 u는 T_j-이웃이다. 보조정리 3(a)에 의해 u는 R_j + w_j에 이웃이 r 하나뿐이고, 나머지 두 이웃은 R_{j+1}(≠ R_j, (I2))의 끝점이다. ✓
- 닫는 정점의 유일성, "Σ의 정점의 세 이웃이 모두 영역 정점", 닫는 정점과 경로의 일대일 대응을 확인했다.
  - 닫는 정점 w_j의 세 번째 이웃은 p_j ∈ R_{j−1}(또는 Z)이므로 영역 정점이다.
  - 한 정점이 경로 둘을 닫으려면 이웃이 4개 필요하다.
- 사적 결합이 두 번 오는 일은 없다. 내부 정점은 S-이웃이 하나, 끝점은 닫는 정점 + 하나, Z 정점은 하나다. 그리고 u에서 v로 가는 비-닫기 결합은 u가 닫는 경로 R_u ∌ v로 향하지 않으므로 u의 사적 결합이다. ✓
- 영역 경로의 차수는 모두 짝수이고 2 이상이다(보조정리 3(b), t₁ ≠ t₂). ✓
- 영역을 여러 T_j로 정의하는 문제: 결론 (I2)와 (I3)이 고정된 S 기준의 성분과 S-이웃에 대한 명제이므로 문제없다. ✓
- **더 간단한 결말(R1).** 사슬은 언제나 한 단계 더 늘릴 수 있다. |R_j| ≥ 2이므로 p_{j+1}이 있고, G가 K₄가 아니므로 보조정리 3이 항상 적용된다. 그런데 (I2)에 의해 R₁, R₂, …는 G−S의 **서로 다른** 성분이다. G가 유한하므로 모순이다. 세기 절 전체를 이 세 줄로 바꿀 수 있고, 그러면 "영역 정의" 관련 검토 항목도 사라진다.

### 6. 따름 절 — **대체로 맞음. 보강 필요**

  - D3 ≥ 1: cost = m₁₂ + e(S) + D3|S| ≥ m₁₂ + |S| ≥ fr이고, 상한은 fr이다. 한 줄 덧붙이면 된다.
  - D3 = 0: 정리에 의해 ioct = fr < ∞이므로 OPT = 0이다.
- Choi–Nakajima–Rim 재유도: fr ≤ OCT ≤ ioct = fr. ✓
- JMOPSvL 정리 11과의 충돌: 이 정리와 평면 max-cut의 다항 시간 알고리즘에서 조건부로 맞게 따라 나온다. 그 논문 증명의 평면성 빈틈은 `theorem_delta3.md`에 이미 기록되어 있어 서로 일관된다. 다만 발표된 NP-완전성 결과와 정면으로 부딪히므로, 외부 전문가 검토와 문헌 조사(이 강화판이 이미 알려진 결과인지)를 권한다.
