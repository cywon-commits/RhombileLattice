이웃 3 격자 갤러리

모든 사이트의 이웃이 3개 이하인데도 좌절이 있는 격자 다섯 가지. 각 그림은 0 < D3 < 1에서의 정확한 바닥상태다. 매칭으로 Ising 바닥상태를 구한 뒤, 좌절 결합마다 한 끝점을 서로 이웃하지 않게 골라 상태 3으로 바꿨다(2-SAT). 에너지가 하한 D3·fr과 같으므로 최적이 인증된다.

모든 격자에서 상태 3 사이트 수가 Ising 좌절 결합 수 fr과 같다. 상태 3 하나가 좌절 결합 하나를 치유한다(정리 C). 같은 배치가 0 < D3 < 1 전 구간의 바닥상태이고, D3 ≥ 1이면 상태 3을 모두 1·2로 되돌린 Ising 바닥상태가 된다. 그림 속 모든 결합은 서로 다른 상태를 잇는다(같은 상태 결합 0개).
