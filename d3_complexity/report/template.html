세 번째 색의 값

좌절된 격자에서 세 번째 상태에 비용 D3를 매기면, 바닥상태는 언제 그 상태를 쓰고 언제 버리는가. 그리고 그 바닥상태를 컴퓨터가 정확히 구할 수 있는가.

상태 1상태 2상태 3 (비용 D3)같은 상태끼리 맞닿은 결합 (에너지 1)

한눈에: 이 작업에서 새로 알아낸 것

  • 결함 하나가 풀 수 있는 좌절은 이웃 수의 절반까지다.상태 3 사이트 하나는 좌절 결합을 최대 ⌊d/2⌋개 없앤다. 이 한 줄에서 아래 결과가 모두 나온다.
  • 전이점은 보편적으로 D3* = ⌊Δ/2⌋다.D3가 최대 이웃 수 Δ의 절반(내림) 이상이면 바닥상태에 상태 3이 전혀 없다. 이 값은 모든 Δ에서 실제로 도달된다.
  • 삼각 격자의 3, 펜로즈 쌍대의 2, 희석 결함의 2가 한 원리로 설명된다.수치로만 보던 꺾임들이 모두 ⌊Δ/2⌋ 또는 사이트별 ⌊d/2⌋다.
  • 바닥상태의 상태 3 사이트는 고립되어 있고, 이웃은 정확히 2:2다.Δ = 4이고 1 < D3 < 2이면 예외가 없다. 펜로즈 조각에서 28개 중 28개가 그랬다.
  • D3 ≥ ⌊Δ/2⌋이면 큰 계의 바닥상태를 정확하게 구할 수 있다.평면 격자라면 매칭 알고리즘 한 번이면 된다. 어닐링 결과를 검증할 기준이 생긴다.
  • 이웃 3 격자에서는 상태 3이 좌절 결합을 하나씩 치유한다.에너지는 min(D3, 1) × (Ising 좌절 수)로, D3 = 1에서 단 한 번 꺾인다. 매칭과 2-SAT만으로 정확한 바닥상태를 구하고 인증한다. 사이트 수천 개도 몇 초면 된다.
  • 아무 평면 격자나 "깎으면" 이웃 3 격자가 된다.좌절은 원래 격자에서 이웃 수가 홀수인 꼭짓점 자리에 생긴다. 깎은 펜로즈 준결정은 펜로즈 쌍대와 좌절 위치가 같다.
  • 1↔2 대칭이 어려움을 막는다.상태 3의 비용은 자기장과 달리 상태 1과 2를 구별하지 않는다. 그래서 Barahona식 NP-hard 증명이 그대로 통하지 않는다. 이 과정에서 인용하려던 문헌의 오류도 찾았다.

1계의 소개

격자의 각 사이트에 세 상태 1, 2, 3 중 하나가 놓인다. 이웃한 두 사이트가 같은 상태이면 에너지 1을 낸다. 이것이 반강자성 3-상태 Potts 모형이다. 여기에 상태 3에만 단일 이온 이방성 D3 ≥ 0을 준다. 상태 3인 사이트마다 에너지 D3를 더 낸다.

E(s) = (같은 상태끼리 맞닿은 결합의 수) + D3 × (상태 3인 사이트의 수)

상태 3은 사이트를 지우는 것과 다르다. 상태 3끼리 이웃해도 같은 상태이므로 에너지 1을 낸다. 물리적으로는 비자성 상태, 다른 궤도 상태, 또는 다른 종류의 원자처럼 "쓰면 비용이 드는 세 번째 선택지"로 생각하면 된다.

이 계가 흥미로운 이유는 좌절 때문이다. 삼각형 하나만 봐도 알 수 있다.

그러니 D3는 "좌절을 해소하는 값"과 "세 번째 상태를 쓰는 값" 사이의 저울이다. D3가 작으면 상태 3을 써서 좌절을 풀고, D3가 크면 좌절을 그대로 둔다. 이 연구는 그 저울이 정확히 어디서 기우는지, 그리고 그 바닥상태를 효율적으로 계산할 수 있는지를 묻는다.

대상은 평면 격자다. 프로젝트의 격자들(삼각 격자의 부분 그래프, 마름모 격자, 펜로즈 타일의 쌍대)이 모두 평면이다. 최대 이웃 수를 Δ, 사이트 v의 이웃 수를 d(v)로 쓴다.

2두 극한

저울의 양 끝은 잘 알려져 있다. 삼각 격자로 보자.

D3 → 0: 세 상태 모두 공짜에 가깝다

세 부격자로 칠하면 좌절이 전혀 없다. 상태 3이 사이트의 1/3이라서 에너지는 사이트당 D3/3이다.

D3 → ∞: 상태 1, 2만 쓴다 (Ising)

Wannier 바닥상태. 모든 삼각형에 같은 상태 결합이 정확히 하나씩 있어 사이트당 에너지 1이다.

계산 관점에서 두 끝은 성격이 정반대다.

  • D3가 매우 크면 평면 Ising 바닥상태 문제다. 이것은 매칭 알고리즘으로 정확히 풀린다(Bieche–Maynard–Rammal–Uhry 1980, Barahona 1982). 큰 계에서도 바닥상태를 정확히 구할 수 있다.
  • D3 → 0이면 "좌절 없는 칠하기가 있는가", 즉 평면 3색칠 문제를 포함한다. 이 문제는 이웃 수 4 이하 평면 그래프에서도 NP-완전이다(Garey–Johnson–Stockmeyer 1976). 일반적으로 효율적인 정확 알고리즘이 없다고 믿어진다.

그렇다면 D3를 키워 가는 도중 어디선가 문제가 쉬워진다. 그 지점을 찾는 것이 첫 번째 목표였다.

3핵심 원리: 결함 하나가 풀 수 있는 좌절

상태 3인 사이트 v를 하나 골라, 그 상태를 1이나 2로 바꾸면 에너지가 얼마나 변하는지 세어 보자. 이웃 중 상태 1인 것을 n₁개, 상태 2인 것을 n₂개, 상태 3인 것을 a개라 하자. v를 이웃에 더 적은 쪽 색으로 바꾼다.

바꾸기 전: 상태 3

가운데 결합은 모두 정상이다. 대신 D3를 낸다.

가장 나쁜 경우: 이웃이 반반

어느 색으로 바꿔도 같은 상태 결합이 d/2 = 3개 생긴다.

이웃이 한쪽에 몰린 경우

적은 쪽 색(여기서는 2)으로 바꾸면 결합 1개만 생긴다.

바꿨을 때의 에너지 변화는 정확히

ΔE = min(n₁, n₂) − a − D3 ≤ ⌊d(v)/2⌋ − D3

이다. 새로 생기는 같은 상태 결합은 min(n₁, n₂)개이고, 상태 3끼리의 결합 a개는 사라지고, D3는 돌려받는다. min(n₁, n₂)는 n₁ + n₂의 절반을 넘을 수 없으므로 부등식이 나온다.

새로 정리한 원리

상태 3 사이트 하나가 해소해 주는 좌절 결합은 최대 ⌊d/2⌋개다. 그 값은 이웃이 두 색으로 정확히 반씩 나뉘고 이웃에 상태 3이 없을 때만 나온다. 따라서 D3가 ⌊d/2⌋ 이상이면 그 사이트에서 상태 3은 비용만큼의 값을 하지 못한다.

4보편 전이점 D3* = ⌊Δ/2⌋

앞의 계산은 사이트 하나의 이웃 수에만 의존하고, 다른 사이트의 현재 상태와는 무관하다. 그래서 상태 3 사이트를 하나씩 바꿔 나가도 매번 에너지가 늘지 않는다. 상태 3의 개수는 매번 하나씩 줄어드므로 결국 상태 3이 없는 배치에 도달한다.

정리 A 증명

D3 ≥ ⌊Δ/2⌋이면 상태 3을 전혀 쓰지 않는 바닥상태가 있다. D3 > ⌊Δ/2⌋이면 모든 바닥상태가 상태 3을 쓰지 않는다. 사이트별로도 성립한다. ⌊d(v)/2⌋ < D3인 사이트는 어떤 바닥상태에서도 상태 3이 아니다.

이 경계는 더 낮출 수 없다: 바퀴 그래프

경계가 너무 보수적이라면 쓸모가 적다. 그런데 모든 Δ에 대해 D3가 ⌊Δ/2⌋보다 조금만 작아도 상태 3이 꼭 필요한 격자 조각이 있다. 바퀴 WΔ, 즉 중심 하나와 길이 Δ인 테두리로 된 그래프다.

W₄, 두 색만: 에너지 2

W₄, 중심만 상태 3: D3

W₅, 두 색만: 에너지 3

W₅, 중심만 상태 3: D3 + 1

두 색만 쓰면 삼각형 Δ개 각각에 같은 상태 결합이 하나씩 필요하다. 바퀴살 결합은 삼각형 두 개가 공유하므로 최소 ⌈Δ/2⌉개가 남는다. 중심을 상태 3으로 바꾸면 테두리 사이클만 남는다. 테두리의 에너지는 짝수 길이면 0, 홀수 길이면 1이다.

새로 알아낸 것 증명 계산 확인

경계 ⌊Δ/2⌋은 모든 Δ ≥ 3에서 빡빡하다. 이전에는 Δ = 3, 4, 6의 예만 알고 있었다. 바퀴 WΔ는 가장 작은 증거다. D3 < ⌊Δ/2⌋이면 모든 바닥상태가 중심에 상태 3을 둔다.

6바닥상태의 국소 구조

3장의 계산을 바닥상태에 적용하면, 상태 3을 바꿔도 에너지가 줄지 않아야 한다. 즉 모든 상태 3 사이트는 min(n₁, n₂) ≥ a + D3를 만족한다. 이 부등식 하나로 바닥상태의 국소 모양이 엄격하게 제한된다.

이웃 수 4인 격자에서 1 < D3 < 2일 때 가능한 모양과 불가능한 모양은 다음과 같다.

허용: 1, 2, 1, 2

허용: 1, 1, 2, 2

금지: 1, 2, 2, 2

가운데를 1로 바꾸면 결합 1개로 D3 > 1을 아낀다.

금지: 상태 3끼리 이웃

금지: 이웃 3개인 사이트

새로 알아낸 것 증명 계산 확인

Δ ≤ 4이면 D3 > 0인 모든 바닥상태에서 상태 3 사이트끼리는 이웃하지 않는다. 1 < D3 < 2이면 모든 상태 3 사이트는 이웃이 정확히 4개이고, 그 상태는 2:2로 나뉜다. 펜로즈 조각(D3 = 1.5)에서 상태 3 마름모 28개가 모두 이 모양이었다. 무작위 평면 그래프 200개의 모든 바닥상태에서도 위반이 없었다.

보류된 backbone 연구에서 "상태 3 이웃이 2:2인가 1:3인가"를 경험적으로 보고 있었다. 이 결과는 그 질문에 답한다. 2:2는 D3가 1을 넘으면 반드시 성립하는 성질이다. D3 < 1에서만 1:3이 가능하다.

7정확히 풀리는 영역

정리 A에 따르면 D3 ≥ ⌊Δ/2⌋에서 바닥상태 문제는 상태 1, 2만 쓰는 Ising 문제와 같다. 평면 격자의 Ising 바닥상태는 다음 절차로 정확히 구한다.

실용적 가치

프로젝트의 exact_Einf.py는 D3 = ∞ 전용이었다. 정리 A는 그 결과가 삼각 격자 부분 그래프에서 D3 ≥ 3, 이웃 4개 격자에서 D3 ≥ 2까지 그대로 정확한 바닥상태임을 보장한다. 이 범위에서 시뮬레이티드 어닐링 결과를 정확해와 직접 비교할 수 있다.

8이웃 3 격자: 상태 3의 일대일 치유

모든 사이트의 이웃이 3개 이하인 격자에서는 이야기가 특히 깔끔해진다. 3장의 원리에 따르면 상태 3 하나가 풀 수 있는 좌절은 ⌊3/2⌋ = 1개다. 그래서 상태 3은 좌절 결합을 하나씩 치유하는 역할만 한다.

치유의 방법

먼저 상태 1, 2만 쓰는 Ising 바닥상태를 구한다. 이웃이 3개 이하이므로 좌절 결합들은 서로 끝점을 공유하지 않는다. 좌절 결합마다 끝점 하나를 골라 상태 3으로 바꾸면 그 결합이 사라진다. 고른 사이트끼리 이웃하지만 않으면 새 좌절도 생기지 않는다.

① Ising 바닥상태

삼각 기둥. 두 삼각형에 좌절 결합(점선)이 하나씩 있다.

② 치유한 배치

좌절 결합마다 한 끝을 상태 3으로 바꿨다. 두 상태 3은 서로 이웃하지 않는다. 좌절 결합은 0개다.

정리 C 증명

이웃 3 이하 격자에서 0 ≤ D3 ≤ 1이면, 바닥상태 에너지는 D3 × fr 이상이다. 여기서 fr은 Ising 바닥상태의 좌절 결합 수다. 증명은 짧다. 상태 3 사이트를 하나씩 상태 1이나 2로 되돌리면, 되돌릴 때마다 좌절 결합이 1개 이하로 생긴다.

치유가 가능하면 바닥상태 에너지는 정확히 E(D3) = min(D3, 1) × fr이다. 치유 가능이란, 어떤 Ising 바닥상태에서 좌절 결합의 끝점들을 서로 이웃하지 않게 고를 수 있다는 뜻이다. 이때 에너지 곡선은 D3 = 1에서 단 한 번 꺾이고, 상태 3 사이트 수는 정확히 fr이다.

바닥상태를 구하고 인증하는 알고리즘

  1. Ising 바닥상태: 홀수 면(좌절 전하)들을 쌍대 그래프의 최단 경로로 짝짓는다(최소 가중 완전 매칭). 짝을 잇는 경로가 가로지르는 결합이 좌절 결합이다.
  2. 치유할 사이트 고르기: 좌절 결합마다 두 끝점 중 하나를 고르되, 고른 사이트끼리 이웃하지 않게 한다. 이것은 2-SAT 문제라서 선형 시간에 풀린다.
  3. 인증: 결과 배치의 에너지는 D3 × fr로 하한과 같다. 따라서 더 찾아볼 필요 없이 바닥상태다. 같은 배치가 0 < D3 < 1 전 구간의 바닥상태이고, D3 ≥ 1이면 1단계의 Ising 바닥상태가 바닥상태다.

시뮬레이티드 어닐링은 "지금까지 찾은 가장 낮은 값"만 준다. 이 방법은 배치와 최적성 증명을 함께 준다. 사이트 약 1,700~3,000개 격자(무작위 거품, 결함 있는 벌집, 깎은 펜로즈)를 각각 15초 안에 풀었다.

복잡한 이웃 3 격자를 만드는 법: 깎기

평면 그래프는 모든 면이 짝수 고리일 때만 이분 그래프다. 그래서 이웃 3이면서 좌절이 있는 격자를 만들려면 홀수 면을 넣어야 한다. 가장 체계적인 방법은 깎기다. 아무 평면 격자에서 이웃이 d개인 꼭짓점을 작은 d각형으로 바꾸면, 모든 사이트의 이웃이 3개가 된다.

깎기 전: 이웃 5개인 꼭짓점

깎은 뒤: 오각형 (홀수 면 = 좌절 전하)

원래 면은 길이가 두 배가 되어 항상 짝수다. 따라서 좌절 전하는 원래 격자에서 이웃 수가 홀수인 꼭짓점 자리에 정확히 생긴다. 깎은 벌집은 별 격자, 깎은 마름모 격자는 삼각형과 육각형, 깎은 펜로즈는 삼각형·오각형·칠각형이 준주기적으로 놓인 격자다. 깎은 펜로즈의 좌절 위치는 5장의 펜로즈 쌍대(이웃 4개)와 같다. 같은 좌절 배치를 이웃 3과 4에서 비교할 수 있다.

항상 치유할 수 있을까

추측 C.5 계산 확인 증명 미완

K₄(사면체)가 아닌 연결된 이웃 3 이하 그래프는 항상 치유 가능하다.

정점 12개 이하인 연결 그래프 27,523개를 전부 조사했는데, 예외는 K₄뿐이었다. 격자와 무작위 그래프 약 3,700건에서도 예외가 없었다. 이 추측은 두 고전 결과의 강화판이다. Brooks 정리는 K₄가 아니면 세 색으로 칠할 수 있다고 말한다. Choi–Nakajima–Rim(1989)은 이웃 3 이하에서 "정점을 지워 이분 그래프로 만드는 최소 개수 = fr"임을 보였다. 이 추측은 그렇게 지우는 정점들을 서로 이웃하지 않게 고를 수 있다고 말한다.

추측이 참이면 이웃 3 평면 격자의 바닥상태는 모든 D3에서 다항 시간에 정확히 풀린다. 에너지는 닫힌 식 min(D3, 1) × fr이다. 증명 과정에서 "어떤 최대 컷이든 치유 가능하다"는 더 강한 명제는 거짓임을 확인했다(사이트 18개 반례). 그래서 증명에는 최대 컷을 바꾸는 조작이 필요하다.

9어려운 쪽: 계산 복잡도

이제 반대 방향의 질문이다. D3가 0과 ⌊Δ/2⌋ 사이에 고정되어 있을 때, 바닥상태를 정확히 구하는 효율적인 방법이 있을까? 원래 추측은 "그 구간에서는 전부 NP-hard, 즉 효율적인 방법이 없다"였다. 지금까지의 지형은 다음과 같다.

왜 어려운 쪽의 증명이 어려운가

평면 Ising은 쉽지만 자기장을 걸면 NP-hard가 된다(Barahona 1982). 상태 3의 비용 D3도 일종의 장처럼 보인다. 그런데 결정적인 차이가 있다.

NP-hard 증명은 보통 논리 회로를 격자 위에 그려 넣는 방식이다. 이때 "참"과 "거짓"을 가리키는 공통 기준이 필요하다. 자기장은 그 기준을 준다. D3는 상태 1과 2를 구별하지 않으므로 기준을 주지 못한다. 기준 신호를 격자 전체에 전달하려면 신호선끼리 교차해야 하는데, 평면에서는 교차를 흉내 내는 부품(교차 가젯)이 필요하다.

우리는 삼각형을 이용한 방식을 시도했다. 비용이 정확히 (삼각형 수) × D3가 되는 바닥상태는 "각 삼각형에 상태 3이 정확히 하나"인 칠하기뿐이다. 그 칠하기에서 삼각형 하나는 다음처럼 동작하는 스위치가 된다.

새로 알아낸 것

1. 인용하려던 문헌의 오류. Johnson 외(arXiv:2211.12887)는 "평면·이웃 3 이하 그래프에서 이 종류의 문제가 NP-완전"이라고 주장한다. 그런데 그 구성은 일반적으로 평면이 아니다. 반례를 찾았고, 이 구성이 평면이 되는 경우에는 모든 절이 한 면 위에 놓여 공식이 쉬운 부류로 떨어진다는 것도 보였다(Pilz 2019의 결과와 결합). 증명

2. 막히는 이유. 이웃 수 3인 격자에서는 "비용이 정확히 (삼각형 수) × D3인 바닥상태가 있는가"가 평면 NAE류 문제가 된다. 평면 Boolean 제약 문제의 분류(Dvořák–Kupec, Kazda–Kolmogorov–Rolínek)에 비추어 보면 이 문제는 다항 시간일 가능성이 높다. 삼각형 4개까지로 된 부품 약 5만 개를 전수 조사했는데, 어려움을 만드는 부품은 하나도 없었다. 계산 확인

물리적 의미. 세 번째 상태의 비용은 자기장과 달리 두 상태의 대칭을 깨지 않는다. 그 대칭 때문에 Barahona식 어려움이 자동으로 따라오지 않는다. 실제로 이웃 3 격자에서는 8장의 치유 정리가 바닥상태를 정확히 준다.

10남은 질문

  • 이웃 수 4인 평면 격자(펜로즈 쌍대, 카고메형)에서 0 < D3 < 2는 NP-hard인가? 삼각형 꼭짓점이 바깥 결합을 2개 가지므로 조건이 NAE보다 풍부하다. 같은 분류 기준으로 "어려움을 만드는 부품"을 찾으면 곧바로 NP-hard가 증명된다. 가장 가능성 높은 다음 단계다.
  • 치유 추측(C.5)의 증명. 참이면 이웃 3 평면 격자는 모든 D3에서 다항 시간이고, 원래 추측("0 < D3 < ⌊Δ/2⌋에서 NP-hard")은 Δ = 3에서 틀린다. 복잡도 결론에는 평면 그래프만 증명해도 충분하다.
  • 펜로즈 쌍대의 작은 꺾임(D3 = 1, 1.25)이 가장자리 효과인지, 더 큰 조각이나 주기 근사로 확인해야 한다.

주의. 계산 복잡도는 바닥상태를 "정확히" 구하는 난이도에 대한 말이다. 유리질 거동이나 느린 동역학과 관련이 있을 수 있지만, 직접적인 연결은 아니다.
