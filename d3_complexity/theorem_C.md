# 정리 C: 이웃 3개 격자에서 상태 3은 좌절 결합을 하나씩 치유한다

상태: **증명** (C.1–C.3). 수치 확인은 `hub_test.py`, `gap_hunt.py`, `hub_tjoin.py`에 있다. 날짜는 2026-09-27.

## 기호

- G는 최대 차수 Δ ≤ 3인 그래프다(평면일 필요는 없다).
- fr(G) = min_{t: V→{1,2}} (같은 색 결합 수). Ising 바닥상태의 좌절 결합 수다.
- ioct(G)는 독립 홀수 사이클 횡단(독립집합 S로서 G − S가 이분인 것)의 최소 크기다. 없으면 ∞다.
- OPT(D3) = min_s [ 같은 상태 결합 수 + D3 · (상태 3 사이트 수) ].

## C.1 샌드위치 부등식

**정리.** 0 ≤ D3 ≤ 1이면

```
D3 · fr(G)  ≤  OPT(D3)  ≤  min( fr(G),  D3 · ioct(G) ).
```

*증명.*

- **상한.** 상태 1, 2만 쓰면 fr(G)다. 크기 ioct인 독립 횡단 S를 상태 3으로 칠하고 G − S를 두 색으로 칠하면 D3 · ioct(G)다.
- **하한.** 임의의 s를 잡고 S = s⁻¹(3), m₁₂ = 상태 1, 2 사이의 같은 상태 결합 수라 하자.
    1. G − S의 2색칠(s 그대로)에서 출발해 S의 사이트를 하나씩 되돌린다.
    2. 되돌릴 때마다 이미 칠해진 이웃 중 적은 쪽 색을 준다. 이웃이 3개 이하이므로 새 같은 색 결합은 1개 이하다.
    3. 따라서 fr(G) ≤ m₁₂ + |S|이다.
    4. 그러므로 cost(s) = m₁₂ + e(S) + D3|S| ≥ m₁₂ + D3|S| ≥ D3(m₁₂ + |S|) ≥ D3 · fr(G)이다. 두 번째 부등호에 D3 ≤ 1을 썼다. ∎

**따름정리.** ioct(G) ≥ fr(G)이다. (m₁₂ = 0, e(S) = 0인 경우의 3번 부등식이다.)

## C.2 등호 조건: "치유 가능"

**정리.** 0 < D3 < 1에서 다음은 동치다.

- (i) OPT(D3) = D3 · fr(G)
- (ii) ioct(G) = fr(G)
- (iii) 어떤 Ising 바닥상태 t가 있어서, 그 좌절 결합 각각에서 끝점을 하나씩 골라 **서로 이웃하지 않게** 할 수 있다.

(iii)을 "G는 **치유 가능**하다"고 부른다. 고른 끝점을 상태 3으로 바꾸면 모든 좌절 결합이 사라진다.

*증명.*

- **(i) ⇒ (ii).** C.1 하한의 등호 조건이다. D3 < 1이므로 m₁₂ = 0, e(S) = 0이고 |S| = fr(G)여야 한다. 그러면 S는 크기 fr(G)인 독립 횡단이다.
- **(ii) ⇒ (iii).** 크기 fr(G)인 독립 횡단 S로 C.1의 되돌리기를 하면 총 같은 색 결합이 fr(G) 이하다. 최소값이 fr(G)이므로 결과 t는 Ising 바닥상태이고, S의 각 사이트가 정확히 하나씩 좌절 결합을 만든다. S가 독립이므로 그 결합의 다른 끝점은 S 밖에 있다. 그래서 S는 t의 좌절 결합들에서 끝점 하나씩을 고른 독립집합이다.
- **(iii) ⇒ (i).** 고른 끝점 집합 S를 상태 3으로 바꾼다. S의 사이트가 좌절 결합을 두 개 가질 수는 없다. 그러면 그 사이트를 뒤집어 Ising 에너지를 낮출 수 있기 때문이다. 따라서 |S| = fr(G)이고, 남은 결합은 모두 정상이며, S는 독립이다. 비용은 D3 · fr(G)다. ∎

**물리적 해석.** 이웃 3개 격자에서 상태 3 사이트 하나는 좌절 결합을 정확히 하나 치유한다. 격자가 치유 가능하면 바닥상태 에너지는 D3 전 구간에서

```
E(D3) = min(D3, 1) · fr(G)
```

이다. 즉 **D3 = 1에서 한 번만 꺾이고**, 상태 3의 개수는 D3 < 1에서 정확히 fr(G)다. T(펜로즈)(좌절 54, 상태 3 54개)와 무작위 이웃-3 격자(좌절 12, 상태 3 12개)의 정확한 곡선이 이 형태였다.

## C.3 허브 완화의 값

상태 3끼리의 결합 벌점을 빼면 "허브 모형"이 된다. 허브 모형의 최적값은 0 ≤ D3 ≤ 1에서 **항상 정확히 D3 · fr(G)**다.

- 하한: C.1의 하한 논증은 e(S)를 쓰지 않는다.
- 상한: 바닥상태의 좌절 결합마다 끝점 하나를 상태 3으로 두면 D3 · fr(G)다.

평면 격자에서는 허브 모형이 쌍대 그래프의 T-join(매칭)으로 풀린다. `hub_tjoin.py`가 MILP 값과 16/16 일치했다.

따라서 **실제 문제와 허브 모형의 차이 = OPT − D3·fr(G)이고, 이 차이가 0 ⇔ 치유 가능**이다.

## C.5 추측: 치유 정리 (Brooks형)

**추측.** 최대 차수 3 이하인 연결 그래프 G가 K₄가 아니면 ioct(G) = fr(G)다. 즉 G는 치유 가능하다.

- **Brooks 정리(1941)와의 관계.** Brooks 정리는 이런 G가 3색칠 가능함(ioct < ∞)을 말한다. 이 추측은 색 3 부류를 **fr(G)개까지 줄일 수 있다**고 말한다.
- **Choi–Nakajima–Rim(1989)과의 관계.** 그들은 최대 차수 3에서 "정점을 지워 이분으로 만드는 최소 개수 = fr(G)"를 보였다. 이 추측은 지우는 정점들이 **서로 이웃하지 않게** 고를 수 있다는 강화판이다.
- **추측이 참일 때의 결과.**
    - 최대 차수 3 평면 그래프에서 모든 D3 > 0에 대해 OPT(D3) = min(D3, 1)·fr(G)이다(K₄ 성분은 따로 min(2, 1 + D3)).
    - 따라서 평면 max-cut 하나로 **다항 시간에** 풀린다. 원래 추측("0 < D3 < ⌊Δ/2⌋에서 NP-hard")은 Δ = 3에서 **틀리게 된다.**
    - 비평면 최대 차수 3 그래프에서는 모든 D3 > 0에서 max-cut과 같은 난이도다.
    - `perfect_colouring_obstruction.md`의 관찰(완벽한 칠하기 판정이 평면에서 쉬워 보임)도 이것으로 설명된다. ioct = k ⇔ fr = k이기 때문이다.
- **증명 방향.** 최대 컷과 끝점 선택 중 "충돌(이웃한 선택 쌍)"이 가장 적은 것을 잡는다. 충돌 uw가 있다고 하자.
    - u, w의 파트너 교체, 또는 u와 w를 동시에 반대편으로 옮기는 회전으로 새 선택을 만들 수 있다. 이 회전은 컷 값을 바꾸지 않는다.
    - 이 두 조작이 모두 막히는 국소 구조가 K₄뿐임을 보이면 된다(작업 중).

## C.5a 증명 시도: 확보한 부분과 막힌 곳 (2026-09-27)

**설정.** 최대 컷 (A, B)를 잡는다. 좌절(같은 쪽) 결합들의 집합 M은 매칭이고, 모든 사이트는 같은 쪽 이웃을 1개 이하 가진다(아니면 뒤집어 컷이 커진다). 끝점 선택 S(M의 각 결합에서 끝점 하나)에 대해, 충돌 κ(S)는 S 안의 간선 수다.

**보조정리 L1 (충돌의 국소 구조, 증명).** uw가 충돌이면(u, w ∈ S) 다음이 성립한다.
- u와 w는 서로 반대쪽에 있다. u의 짝 u′은 u 쪽에, w의 짝 w′은 w 쪽에 있다.
- deg u = deg w = 3이다.
    - deg u = 2라면 u를 뒤집어도 컷 값은 그대로다. 그러면 w가 같은 쪽 이웃 2개(w′, u)를 갖게 되어 w를 뒤집으면 컷이 커지므로 모순이다.
- u의 세 번째 이웃 x는 M에 속하지 않거나 x = w′이다. w의 세 번째 이웃 y도 마찬가지로 M에 속하지 않거나 y = u′이다.

**보조정리 L2 (회전, 증명).** 충돌 uw에서 u와 w를 동시에 뒤집으면 컷 값이 변하지 않는다.
- uu′, ww′이 컷에 들어가고(+2), ux, wy가 컷에서 빠진다(−2). uw는 그대로 컷에 남는다.
- 따라서 결과도 최대 컷이다. 새 좌절 결합은 ux, wy(또는 uw′, wy)다.

**보조정리 L3 (끝점 교체, 자명).** 같은 컷에서 S의 u를 짝 u′으로 바꾸면 κ는 |N(u′)∩S| − |N(u)∩S|만큼 변한다.

**거짓으로 판명된 강한 판.** "**모든** 최대 컷이 치유 가능하다"는 거짓이다.
- 반례: `hub_runs/strong_version_counterexample.json`(사이트 18개, fr = 5, 최대 컷 13개 중 1개가 치유 불가능).
- 원인은 "두 삼각형을 결합 하나로 이은" 구조다. 결합이 좌절되고 두 삼각형의 좌절 결합이 반대쪽에 있으면, 두 끝점 모두에 2-SAT 모순 사슬(길이 2)이 생긴다.
- 치유가 안 되는 최대 컷은 드물었고(탐색 약 400그래프에서 4개), **모두 L2의 회전 한 번으로 치유 가능한 최대 컷이 되었다.**

**따라서 증명 구조는** "모든 최대 컷 × 끝점 선택 중 κ가 최소인 상태를 잡고, κ ≥ 1이면 L2·L3로 κ를 줄이거나 K₄임을 보인다"가 되어야 한다.
- L1–L3에서 나오는 필요조건: u′, w′, x, y가 각각 S에 이웃을 가진다.
- 막힌 곳: 이 조건들만으로는 모순이 나오지 않는다. 회전 뒤의 충돌 변화를 추적하는 퍼텐셜 함수가 필요하다.

**전수 검증.** 연결되고 최대 차수 3 이하인 그래프를 정점 10개까지 **전부**(2,569개) 생성해 확인했다(`exhaustive_heal.py`). K₄ 외에는 모두 치유 가능하다. 그래프 수는 n = 3…10에서 2, 6, 10, 29, 64, 194, 531, 1733개다. 정점 11개(5,524개), 12개(19,430개)도 전부 확인했다. 정점 12개까지 합계 27,523개에서 K₄ 외의 치유 불가능 그래프는 없다.

**평면에서의 대안 경로.** 평면 그래프에서는 쌍대 삼각분할에서 최소 T-join J의 각 간선마다 양옆 삼각형 중 하나를 고르되, 고른 삼각형끼리 변을 공유하지 않게 하는 문제가 된다.
- 최소성에서 "각 삼각형은 J의 간선을 하나만 가진다"가 나온다.
- 충돌은 두 종류뿐이다.
    - (I) 한 꼭짓점에서 연속한 J 간선 사이에 삼각형이 정확히 2개인 부채꼴
    - (II) 사각형의 대변 두 개가 J에 있는 Z자 모양
- 복잡도 응용(평면 Δ = 3이 다항 시간)에는 평면 판만으로 충분하다.

## C.5b 증명 (초안, 2026-09-27): 추측 C.5는 평면성 없이 성립한다

상태: **증명 초안.** 평면성을 쓰지 않으므로 일반 이웃-3 그래프에 대한 증명이다. 독립 검토가 필요하다. 아래 모든 그래프는 최대 차수 3 이하이고, G는 연결되어 있으며 K₄가 아니다.

### 기호와 두 가지 기본 사실
- 임의의 X ⊆ V에 대해 φ(X) = |X| + fr(G − X)로 둔다.
- **(F1) 하한.** φ(X) ≥ fr(G)이다. X의 정점을 하나씩 다시 넣을 때 이웃 중 드문 쪽에 두면 새 좌절은 ⌊3/2⌋ = 1개 이하다. X가 독립이 아니어도 성립한다.
- 독립집합 S가 φ(S) = fr이면 **빡빡하다**고 하고, k(S) = fr(G − S)로 둔다. ∅은 빡빡하다.
- **(F2) 목표와의 관계.** k(S) = 0인 빡빡한 S가 있으면 ioct ≤ fr이다. (F1)에서 모든 홀수 사이클 횡단은 크기가 fr 이상이므로 ioct = fr이다.

크기가 최대인 빡빡한 집합을 **최대 빡빡 집합**이라 한다. **최대 빡빡 집합은 k = 0임을 보인다.** 귀류법으로 k(S) ≥ 1인 최대 빡빡 집합 S가 있다고 가정한다.

### 보조정리 1 (덧붙이기)
S가 빡빡하고, v가 G − S의 어떤 최대 컷에서 좌절 결합의 끝점이며, v가 S와 이웃하지 않는다고 하자. 그러면 S + v는 빡빡하다.

증명: 그 컷에서 v를 빼면 좌절 결합이 하나 이상 사라지므로 fr(G − S − v) ≤ k − 1이다. 따라서 φ(S + v) ≤ φ(S) = fr이고, (F1)에 의해 등호다. S + v는 독립이다. ∎

### 보조정리 2 (막힌 구조)
S가 최대 빡빡 집합이면, G − S에서 좌절이 있는 성분은 모두 **홀수 사이클**이다. 그 사이클의 모든 정점은 G에서 차수가 3이고 S-이웃을 정확히 하나 가진다.

증명:
- K를 fr(K) ≥ 1인 성분이라 하고, 최대 컷의 좌절 결합 uv를 잡는다.
- 보조정리 1과 최대성에 의해 v는 S와 이웃하므로 deg_K(v) ≤ 2이다.
- deg_K(v) = 1이면 v를 뒤집어 컷이 커지므로 모순이다. 따라서 v의 K-이웃은 u(같은 쪽)와 v₁(반대쪽)이다. v₁도 같은 쪽이면 뒤집어서 컷이 커진다.
- v를 뒤집으면 값이 같은 최대 컷이 되고, 좌절 결합이 vv₁로 옮겨 간다. 따라서 v₁에도 같은 논증이 적용된다.
- 이렇게 걸어가면 방문하는 정점이 모두 K-차수 2이므로 K는 사이클이다. 좌절이 있으므로 홀수다.
- 각 정점은 S-이웃이 1개 이상이고 차수가 3 이하이므로, S-이웃이 정확히 하나이고 차수가 3이다. ∎

### 보조정리 3 (기본 구조, 여기서 K₄가 빠진다)
T가 최대 빡빡 집합이고, Y가 G − T의 홀수 사이클 성분이며, y ∈ Y이고 t가 y의 유일한 T-이웃이라 하자. 그러면 다음이 성립한다.
- (a) deg t = 3이고, t는 Y에 이웃이 **정확히 하나**(y) 있다.
- (b) t의 나머지 두 이웃은 G − T의 **짝수 차수 경로 성분** Q의 두 끝점이다.
- (c) T′ = T − t + y는 최대 빡빡 집합이고, Q + t는 G − T′의 홀수 사이클 성분이다.

따라서 Y의 정점들의 T-이웃은 모두 서로 다르다.

증명:
- T′은 독립이다. y의 이웃은 t와 사이클 이웃 둘뿐이다.
- fr(G − T − y) = k − 1이다(Y가 경로가 된다). t를 다시 넣으면 t의 남은 이웃은 2개 이하이므로 좌절이 1 이하 늘어난다. 따라서 fr(G − T′) ≤ k이고, (F1)에 의해 = k이다. 크기가 같으므로 T′은 최대 빡빡 집합이고, 보조정리 2가 T′에 적용된다.
- t가 다른 홀수 사이클 성분 Y₂와 이웃하면, 합쳐진 성분은 좌절이 있지만 Y₂의 한 정점이 차수 3이다. 이는 보조정리 2에 모순이다.
- 따라서 fr(G − T′) = (k − 1) + fr(D)이고, D는 t가 속한 성분이다. fr(D) = 1이므로 D는 모든 정점이 차수 2인 홀수 사이클이다. 그러므로 t는 G − T′에서 이웃 t₁, t₂를 가지고 deg t = 3이다.
- D − t는 G − T − y의 한 성분인 t₁–t₂ 경로 W이고, 정점 수가 짝수다.
- **W = Y − y인 경우.** t는 y의 두 사이클 이웃 y⁺, y⁻와 이웃한다. 그러면 y⁺의 유일한 T-이웃도 t이다. 같은 논증을 y⁺에 적용하면 t의 이웃은 {y, y⁺⁺}도 포함해야 하므로 y⁺⁺ = y⁻, 즉 |Y| = 3이다. {t} ∪ Y는 K₄이고 모든 차수가 3이므로 G = K₄가 되어 가정에 어긋난다.
- **그렇지 않은 경우.** W는 G − T의 이분 성분 Q(경로)이고 (a)–(c)가 성립한다. ∎

### 보조정리 4 (사슬 불변식)
Z를 G − S의 홀수 사이클 성분이라 하자. **사슬**을 다음과 같이 정의한다.
- T₀ = S, R₀ = Z로 둔다.
- 단계 j에서 p_{j+1} ∈ R_j를 고른다(R₀ = Z에서는 아무 정점, j ≥ 1에서는 R_j의 정점이고 w_j는 제외).
- w_{j+1}을 p_{j+1}의 T_j-이웃으로 두고, R_{j+1}을 보조정리 3의 경로로 둔다.
- T_{j+1} = T_j − w_{j+1} + p_{j+1}로 둔다.

그러면 모든 j에서 다음이 성립한다.
- (I1) T_j는 최대 빡빡 집합이고, R_j + w_j(j ≥ 1)는 G − T_j의 홀수 사이클 성분이다.
- (I2) R_j는 **G − S의 짝수 경로 성분**이고, Z, R₁, …, R_{j−1}과 다르다.
- (I3) R_j의 정점의 S-이웃은 T_j-이웃에 w_j를 더한 것이다. 내부 정점은 S-이웃이 1개, 끝점은 2개(그중 하나가 w_j)이다.

증명(j에 대한 귀납):
- G − T_j의 성분은 세 종류다. (i) G − S의 성분 중 Z, R₁, …, R_j가 아닌 것(변하지 않고, T_j-이웃과 S-이웃이 같다), (ii) 경로 Z − p₁과 "회전 경로" R_i − p_{i+1} + w_i (1 ≤ i < j), (iii) 홀수 사이클 R_j + w_j.
- 보조정리 3을 (T_j, R_j + w_j)의 정점 r ∈ R_j에 적용한다. r의 T_j-이웃 x는 p들이 아니다(p_i의 이웃은 w_i와 R_{i−1}의 정점뿐이다). 따라서 x ∈ S이고 x ≠ w들이다.
- x가 닫는 경로 R′이 (ii)의 경로가 아님을 보이면 된다.
    - **R′ = Z − p₁인 경우.** x ∈ S가 z⁺와 z⁻ 모두와 이웃해야 하므로 s(z⁺) = s(z⁻)이다. 이는 보조정리 3의 서로 다름에 어긋난다.
    - **R′이 p_{i+1}이 내부인 회전 경로인 경우.** 끝점 y, y′은 p_{i+1}의 R_i-이웃이다. x ∈ S − W가 둘 다와 이웃한다. 그런데 단계 i에서 보조정리 3(a)에 의해 x는 R_i + w_i에 이웃이 하나뿐이어야 한다. 모순이다.
    - **R′이 p_{i+1}이 끝점인 회전 경로인 경우.** 끝점이 w_i이다. x ∈ T_j ∩ N(w_i) ⊆ {p_i, p_{i+1}}인데, 둘 다 R_j와 이웃하지 않는다. 모순이다.
- 따라서 R′은 (i)의 성분이다. 즉 G − S의 성분이고, 앞선 것들과 다르며, S-이웃이 보존된다. ∎

### 영역 세기로 모순
보조정리 4의 모든 사슬이 닿는 경로 성분들을 **영역 경로**라 하고, Z와 영역 경로의 정점을 **영역 정점**이라 한다. Σ는 영역 정점의 S-이웃 전체다.

- **(P3)** 영역 경로 R(닫는 정점 w)의 정점 r에 대해, w가 아닌 S-이웃 u는 R에 이웃이 정확히 하나(r)다. u의 나머지 두 이웃은 다른 영역 경로 R_u의 끝점이다(보조정리 3(a)와 보조정리 4). Z의 정점도 같다.
- **닫는 정점의 유일성.** 경로 R을 닫는 S-정점(두 끝점과 모두 이웃)은 하나뿐이다. 둘째 것이 있으면 (P3)에 의해 R에 이웃이 하나여야 하므로 모순이다.
- **Σ의 모든 정점 x는 이웃 셋이 모두 영역 정점이다.** 사적 이웃 1개가 있고, 닫는 경로 R_x의 끝점이 2개다. 또 x는 영역 경로를 정확히 하나 닫는다.
- 따라서 **|Σ| = 영역 경로의 수**이다(닫는 정점 ↔ 경로의 일대일 대응).
- 모든 영역 정점은 **사적 결합을 정확히 하나** 받는다. Z 정점은 s(z)에서, 경로 내부 정점은 유일한 S-이웃에서, 끝점은 닫는 정점이 아닌 S-이웃에서 받는다. Σ의 각 정점은 사적 결합을 정확히 하나 내보낸다. 따라서 다음이 성립한다.

```
|Σ| = |Z| + Σ_R |R| ≥ 3 + 2·(영역 경로의 수) = 3 + 2|Σ|
```

이는 모순이다. **따라서 최대 빡빡 집합은 k = 0이고, (F2)에 의해 ioct = fr이다.** ∎

### 따름
- **정리 (치유 정리).** K₄ 성분이 없는 최대 차수 3 이하 그래프는 ioct = fr이다. 모든 D3 ≥ 0에서 OPT(D3) = min(D3, 1)·fr이다.
- **평면 이웃-3 격자에서는 모든 D3에서 바닥상태 에너지가 다항 시간에 계산된다**(평면 max-cut). K₄ 성분은 따로 센다(각각 OPT = min(2, 1 + D3)).
- 따라서 Johnson 외 정리 11의 "평면 이웃-3 IOCT NP-완전" 주장은 P = NP가 아니면 거짓이다(`theorem_delta3.md`).
- Choi–Nakajima–Rim의 정리 1(OCT = fr)은 이 정리의 약한 판으로 다시 얻어진다.
