# 정리 C: 이웃 3개 격자에서 상태 3은 좌절 결합을 하나씩 치유한다

상태: **증명** (C.1–C.3). 수치 확인은 `hub_test.py`, `gap_hunt.py`, `hub_tjoin.py`에 있다. 날짜는 2026-09-27.

## 기호

- G는 최대 차수 Δ ≤ 3인 그래프다(평면일 필요는 없다).
- fr(G) = min_{t: V→{1,2}} (같은 색 결합 수). Ising 바닥상태의 좌절 결합 수다.
- ioct(G)는 독립 홀수 사이클 횡단(독립집합 S로서 G − S가 이분인 것)의 최소 크기다. 없으면 ∞다.
- OPT(D3) = min_s [ 같은 상태 결합 수 + D3 · (상태 3 사이트 수) ].

## C.1 샌드위치 부등식

**정리.** 0 ≤ D3 ≤ 1이면

```
D3 · fr(G)  ≤  OPT(D3)  ≤  min( fr(G),  D3 · ioct(G) ).
```

*증명.*

- **상한.** 상태 1, 2만 쓰면 fr(G)다. 크기 ioct인 독립 횡단 S를 상태 3으로 칠하고 G − S를 두 색으로 칠하면 D3 · ioct(G)다.
- **하한.** 임의의 s를 잡고 S = s⁻¹(3), m₁₂ = 상태 1, 2 사이의 같은 상태 결합 수라 하자.
    1. G − S의 2색칠(s 그대로)에서 출발해 S의 사이트를 하나씩 되돌린다.
    2. 되돌릴 때마다 이미 칠해진 이웃 중 적은 쪽 색을 준다. 이웃이 3개 이하이므로 새 같은 색 결합은 1개 이하다.
    3. 따라서 fr(G) ≤ m₁₂ + |S|이다.
    4. 그러므로 cost(s) = m₁₂ + e(S) + D3|S| ≥ m₁₂ + D3|S| ≥ D3(m₁₂ + |S|) ≥ D3 · fr(G)이다. 두 번째 부등호에 D3 ≤ 1을 썼다. ∎

**따름정리.** ioct(G) ≥ fr(G)이다. (m₁₂ = 0, e(S) = 0인 경우의 3번 부등식이다.)

## C.2 등호 조건: "치유 가능"

**정리.** 0 < D3 < 1에서 다음은 동치다.

- (i) OPT(D3) = D3 · fr(G)
- (ii) ioct(G) = fr(G)
- (iii) 어떤 Ising 바닥상태 t가 있어서, 그 좌절 결합 각각에서 끝점을 하나씩 골라 **서로 이웃하지 않게** 할 수 있다.

(iii)을 "G는 **치유 가능**하다"고 부른다. 고른 끝점을 상태 3으로 바꾸면 모든 좌절 결합이 사라진다.

*증명.*

- **(i) ⇒ (ii).** C.1 하한의 등호 조건이다. D3 < 1이므로 m₁₂ = 0, e(S) = 0이고 |S| = fr(G)여야 한다. 그러면 S는 크기 fr(G)인 독립 횡단이다.
- **(ii) ⇒ (iii).** 크기 fr(G)인 독립 횡단 S로 C.1의 되돌리기를 하면 총 같은 색 결합이 fr(G) 이하다. 최소값이 fr(G)이므로 결과 t는 Ising 바닥상태이고, S의 각 사이트가 정확히 하나씩 좌절 결합을 만든다. S가 독립이므로 그 결합의 다른 끝점은 S 밖에 있다. 그래서 S는 t의 좌절 결합들에서 끝점 하나씩을 고른 독립집합이다.
- **(iii) ⇒ (i).** 고른 끝점 집합 S를 상태 3으로 바꾼다. S의 사이트가 좌절 결합을 두 개 가질 수는 없다. 그러면 그 사이트를 뒤집어 Ising 에너지를 낮출 수 있기 때문이다. 따라서 |S| = fr(G)이고, 남은 결합은 모두 정상이며, S는 독립이다. 비용은 D3 · fr(G)다. ∎

**물리적 해석.** 이웃 3개 격자에서 상태 3 사이트 하나는 좌절 결합을 정확히 하나 치유한다. 격자가 치유 가능하면 바닥상태 에너지는 D3 전 구간에서

```
E(D3) = min(D3, 1) · fr(G)
```

이다. 즉 **D3 = 1에서 한 번만 꺾이고**, 상태 3의 개수는 D3 < 1에서 정확히 fr(G)다. T(펜로즈)(좌절 54, 상태 3 54개)와 무작위 이웃-3 격자(좌절 12, 상태 3 12개)의 정확한 곡선이 이 형태였다.

## C.3 허브 완화의 값

상태 3끼리의 결합 벌점을 빼면 "허브 모형"이 된다. 허브 모형의 최적값은 0 ≤ D3 ≤ 1에서 **항상 정확히 D3 · fr(G)**다.

- 하한: C.1의 하한 논증은 e(S)를 쓰지 않는다.
- 상한: 바닥상태의 좌절 결합마다 끝점 하나를 상태 3으로 두면 D3 · fr(G)다.

평면 격자에서는 허브 모형이 쌍대 그래프의 T-join(매칭)으로 풀린다. `hub_tjoin.py`가 MILP 값과 16/16 일치했다.

따라서 **실제 문제와 허브 모형의 차이 = OPT − D3·fr(G)이고, 이 차이가 0 ⇔ 치유 가능**이다.

## C.5 추측: 치유 정리 (Brooks형)

**추측.** 최대 차수 3 이하인 연결 그래프 G가 K₄가 아니면 ioct(G) = fr(G)다. 즉 G는 치유 가능하다.

- **Brooks 정리(1941)와의 관계.** Brooks 정리는 이런 G가 3색칠 가능함(ioct < ∞)을 말한다. 이 추측은 색 3 부류를 **fr(G)개까지 줄일 수 있다**고 말한다.
- **Choi–Nakajima–Rim(1989)과의 관계.** 그들은 최대 차수 3에서 "정점을 지워 이분으로 만드는 최소 개수 = fr(G)"를 보였다. 이 추측은 지우는 정점들이 **서로 이웃하지 않게** 고를 수 있다는 강화판이다.
- **추측이 참일 때의 결과.**
    - 최대 차수 3 평면 그래프에서 모든 D3 > 0에 대해 OPT(D3) = min(D3, 1)·fr(G)이다(K₄ 성분은 따로 min(2, 1 + D3)).
    - 따라서 평면 max-cut 하나로 **다항 시간에** 풀린다. 원래 추측("0 < D3 < ⌊Δ/2⌋에서 NP-hard")은 Δ = 3에서 **틀리게 된다.**
    - 비평면 최대 차수 3 그래프에서는 모든 D3 > 0에서 max-cut과 같은 난이도다.
    - `perfect_colouring_obstruction.md`의 관찰(완벽한 칠하기 판정이 평면에서 쉬워 보임)도 이것으로 설명된다. ioct = k ⇔ fr = k이기 때문이다.
- **증명 방향.** 최대 컷과 끝점 선택 중 "충돌(이웃한 선택 쌍)"이 가장 적은 것을 잡는다. 충돌 uw가 있다고 하자.
    - u, w의 파트너 교체, 또는 u와 w를 동시에 반대편으로 옮기는 회전으로 새 선택을 만들 수 있다. 이 회전은 컷 값을 바꾸지 않는다.
    - 이 두 조작이 모두 막히는 국소 구조가 K₄뿐임을 보이면 된다(작업 중).

## C.5a 증명 시도: 확보한 부분과 막힌 곳 (2026-09-27)

**설정.** 최대 컷 (A, B)를 잡는다. 좌절(같은 쪽) 결합들의 집합 M은 매칭이고, 모든 사이트는 같은 쪽 이웃을 1개 이하 가진다(아니면 뒤집어 컷이 커진다). 끝점 선택 S(M의 각 결합에서 끝점 하나)에 대해, 충돌 κ(S)는 S 안의 간선 수다.

**보조정리 L1 (충돌의 국소 구조, 증명).** uw가 충돌이면(u, w ∈ S) 다음이 성립한다.
- u와 w는 서로 반대쪽에 있다. u의 짝 u′은 u 쪽에, w의 짝 w′은 w 쪽에 있다.
- deg u = deg w = 3이다.
    - deg u = 2라면 u를 뒤집어도 컷 값은 그대로다. 그러면 w가 같은 쪽 이웃 2개(w′, u)를 갖게 되어 w를 뒤집으면 컷이 커지므로 모순이다.
- u의 세 번째 이웃 x는 M에 속하지 않거나 x = w′이다. w의 세 번째 이웃 y도 마찬가지로 M에 속하지 않거나 y = u′이다.

**보조정리 L2 (회전, 증명).** 충돌 uw에서 u와 w를 동시에 뒤집으면 컷 값이 변하지 않는다.
- uu′, ww′이 컷에 들어가고(+2), ux, wy가 컷에서 빠진다(−2). uw는 그대로 컷에 남는다.
- 따라서 결과도 최대 컷이다. 새 좌절 결합은 ux, wy(또는 uw′, wy)다.

**보조정리 L3 (끝점 교체, 자명).** 같은 컷에서 S의 u를 짝 u′으로 바꾸면 κ는 |N(u′)∩S| − |N(u)∩S|만큼 변한다.

**거짓으로 판명된 강한 판.** "**모든** 최대 컷이 치유 가능하다"는 거짓이다.
- 반례: `hub_runs/strong_version_counterexample.json`(사이트 18개, fr = 5, 최대 컷 13개 중 1개가 치유 불가능).
- 원인은 "두 삼각형을 결합 하나로 이은" 구조다. 결합이 좌절되고 두 삼각형의 좌절 결합이 반대쪽에 있으면, 두 끝점 모두에 2-SAT 모순 사슬(길이 2)이 생긴다.
- 치유가 안 되는 최대 컷은 드물었고(탐색 약 400그래프에서 4개), **모두 L2의 회전 한 번으로 치유 가능한 최대 컷이 되었다.**

**따라서 증명 구조는** "모든 최대 컷 × 끝점 선택 중 κ가 최소인 상태를 잡고, κ ≥ 1이면 L2·L3로 κ를 줄이거나 K₄임을 보인다"가 되어야 한다.
- L1–L3에서 나오는 필요조건: u′, w′, x, y가 각각 S에 이웃을 가진다.
- 막힌 곳: 이 조건들만으로는 모순이 나오지 않는다. 회전 뒤의 충돌 변화를 추적하는 퍼텐셜 함수가 필요하다.

**전수 검증.** 연결되고 최대 차수 3 이하인 그래프를 정점 10개까지 **전부**(2,569개) 생성해 확인했다(`exhaustive_heal.py`). K₄ 외에는 모두 치유 가능하다. 그래프 수는 n = 3…10에서 2, 6, 10, 29, 64, 194, 531, 1733개다. 정점 11–12개는 진행 중이다.

**평면에서의 대안 경로.** 평면 그래프에서는 쌍대 삼각분할에서 최소 T-join J의 각 간선마다 양옆 삼각형 중 하나를 고르되, 고른 삼각형끼리 변을 공유하지 않게 하는 문제가 된다.
- 최소성에서 "각 삼각형은 J의 간선을 하나만 가진다"가 나온다.
- 충돌은 두 종류뿐이다.
    - (I) 한 꼭짓점에서 연속한 J 간선 사이에 삼각형이 정확히 2개인 부채꼴
    - (II) 사각형의 대변 두 개가 J에 있는 Z자 모양
- 복잡도 응용(평면 Δ = 3이 다항 시간)에는 평면 판만으로 충분하다.
