# B1 방식의 한계: "완벽한 칠하기" 존재 여부는 (부분 부류에서) 다항 시간이다

상태: 명제 P1은 증명했다. 명제 P2는 계산으로 확인했다. 결론 C는 추론이다. 날짜는 2026-09-26.

## 배경

정리 B1식 환원은 다음 구조를 쓴다. 정점이 겹치지 않는 삼각형 k개가 있는 그래프에서는

"OPT_D3 ≤ k·D3 ⇔ **완벽한 칠하기**가 존재한다"

가 성립한다(D3 ∈ (0,1)). 완벽한 칠하기는 다음 세 조건을 모두 만족하는 3색칠이다.

- 진짜(proper) 3색칠이다.
- 색 3이 삼각형마다 정확히 하나다.
- 삼각형 밖에는 색 3이 없다.

따라서 이 방식으로 평면·최대 차수 3에서 NP-hard를 얻으려면, 평면·최대 차수 3 그래프에서 **완벽한 칠하기의 존재 여부가 NP-hard**여야 한다. 평면성 빈틈(`theorem_delta3.md`)을 교차 가젯으로 메우려는 시도도 이 조건에 달려 있다.

## 명제 P1 (NAE로 번역)

최대 차수 3이고 삼각형들이 정점을 공유하지 않는 그래프 G를 생각하자. 삼각형 t = {p, q, r}의 세 정점은 각각 삼각형 밖의 이웃 x_p, x_q, x_r을 하나씩 가진다. 이 이웃들이 모두 삼각형에 속하지 않는 정점("평범한 정점")이라고 하자. 그러면 다음이 성립한다.

G가 완벽한 칠하기를 가진다 ⇔ 평범한 정점들의 2색칠 c : V_plain → {1,2}가 존재해서

- 평범한 정점끼리의 간선에서 c가 다르고,
- 모든 삼각형 t에서 NAE(c(x_p), c(x_q), c(x_r)), 즉 셋이 모두 같지는 않다.

*증명.* 완벽한 칠하기에서 t의 색 3 정점을 p라 하자. 그러면 q, r ∈ {1,2}이고 q ≠ r이다. 또 q ≠ x_q, r ≠ x_r이므로 q = ¬x_q, r = ¬x_r이다. 따라서 x_q ≠ x_r이다. 역으로 NAE가 성립하면 서로 다른 쌍 (x_q, x_r)을 하나 골라 q = ¬x_q, r = ¬x_r, p = 3으로 칠하면 된다. ∎

## 따름정리 (다항 시간)

G가 평면이면 P1의 조건은 **가중 평면 max-cut 하나**로 판정된다.

- 각 삼각형 t와 그 세 간선을, 삼각형 영역 안에서 x_p–x_q–x_r을 잇는 "가상 삼각형"(가중치 1)으로 바꾼다(Y–Δ 치환). 이렇게 해도 평면성이 유지된다.
- 평범한 정점끼리의 간선에는 큰 가중치 W를 준다.
- 가상 삼각형의 컷 값은 NAE이면 2, 셋이 모두 같으면 0이다.
- 따라서 완벽한 칠하기가 존재한다 ⇔ 최대 컷 = W·|E_plain| + 2·(삼각형 수)이다.
- 평면 max-cut은 다항 시간이다(Moret 1988의 "평면 NAE-3SAT ∈ P"와 같은 논리).

**결론:** 이 부분 부류에서는 B1식 환원으로 NP-hard를 얻을 수 없고, 교차 가젯도 존재하지 않는다(P ≠ NP 가정). `crossover_search.py`가 "반쪽 교차"(점수 2)만 찾은 것과 일치한다.

## 명제 P2 (삼각형끼리 이웃하는 경우)

두 삼각형 t = {p,q,r}, t' = {p',q',r'}이 간선 p–p'로 이어지고, 바깥 이웃 y₁(q), y₂(r), y₃(q'), y₄(r')가 평범한 정점이라 하자. 완벽한 칠하기가 허용하는 (y₁, …, y₄)는 **정확히 NAE₄**다. 즉 넷이 모두 같은 두 경우만 금지된다(전수 계산).

즉 삼각형끼리 이웃하면 크기 4 이상의 NAE 절이 생긴다. **평면 NAE-SAT에서 절 크기가 4 이상이어도 다항 시간인지**가 남은 질문이다.

- 4-사이클 가상 간선만으로는 NAE₄를 표현할 수 없다. 교대 패턴의 컷 값이 4, 나머지 NAE 패턴은 2라서 한 값으로 모이지 않는다.
- 따라서 위 max-cut 번역은 곧바로 확장되지 않는다.

## 결론 C (추론)

- **Δ = 3에서의 선택지:**
  - (a) 평면 {NAE₃, NAE₄, …, ≠} CSP가 NP-hard라면, 삼각형끼리 이웃하는 구조로 교차 가젯과 B1식 증명이 가능하다.
  - (b) 다항 시간이라면 B1 방식은 Δ = 3 평면에서 원리적으로 불가능하다. 이 경우 D3 ∈ (0,1)의 어려움은 완벽하지 않은 최적해, 즉 단색 간선과 색 3 사이의 맞바꿈에서 와야 한다. 이 문제 자체가 다항 시간일 가능성도 열린다.
- **확인할 문헌:** 평면 Boolean CSP 분류(Dvořák–Kupec, ICALP 2015; Kazda–Kolmogorov–Rolínek, SODA 2017)에서 {NAE_k, ≠}의 위치, 그리고 "평면 NAE-SAT(절 크기 ≥ 4)"의 복잡도.
- **Δ = 4에서는 사정이 다르다.** 삼각형 정점이 바깥 간선을 2개 가지므로 색 3 정점을 지우면 간선 2개가 풀린다. 그래서 허용 관계가 NAE보다 풍부하다. B1식 방식과 교차 가젯은 Δ = 4에서 가능성이 더 크다.
