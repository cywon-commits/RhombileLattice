# 치유 정리의 구성적 판 (2026-09-30)

`paper/healing_proof.tex`의 증명을 "크기 최대인 빡빡한 집합" 대신 "막힌(덧붙일 수 없는) 빡빡한 집합" 가정으로 바꿔 본 분석이다. 결론부터 적으면 다음과 같다.

- **증명된 것:** 탐욕적 덧붙이기에 **교환 사슬 탐색**을 더한 알고리즘은 항상 크기 fr의 독립 홀수사이클 횡단을 만든다. fr 계산만 할 수 있으면 다항 번의 호출로 끝난다. 평면이면 fr이 다항 시간이므로 **평면 이웃-3 격자에서 바닥상태 배열을 다항 시간에 구성**할 수 있다.
- **순수 탐욕은 막힐 수 있다 (검토에서 발견):** 교환 없이 덧붙이기만 하면 막히는 경우가 12정점부터 있다. 11정점 이하에는 0개, 12정점 그래프에서 33개, 3-정칙 18정점에서 806개. 평면 예: graph6 `K?`D@`ae?iH_`, S = {4, 8, 10}(빡빡, fr(G − S) = 1, 덧붙일 곳 없음). 따라서 **교환 단계는 반드시 필요하다.** (이전의 "탐욕 972회 무실패"는 무작위 순서 시험이라 이런 경우를 만나지 않았다.)
- 검토: `reviews/constructive_review.md` — 명제는 쓰인 그대로 참, 논리적 빈틈 없음.

## 1. 정의

- 독립 집합 S가 **빡빡하다**: φ(S) = |S| + fr(G − S) = fr(G).
- 빡빡한 S가 **덧붙일 수 있다**: 어떤 v ∉ S에 대해 S + v가 독립이고 빡빡하다. 이는 v가 S와 이웃하지 않고 fr(G − S − v) = fr(G − S) − 1이라는 것과 같다.
- 덧붙일 수 없으면 **막혔다**.
- 크기 s인 빡빡한 집합이 **모두** 막혔다 ⇔ 크기 s + 1인 빡빡한 집합이 없다 ⇔ s가 최대 크기다. (크기 s + 1인 빡빡한 T*에서 아무 u를 빼면, u를 되살려도 좌절이 1 이하로 늘므로 φ(T* − u) ≤ φ(T*) = fr이고, (F1)과 합쳐 T* − u는 빡빡하며 u를 다시 덧붙일 수 있다.)

즉 기존 증명의 "최대 크기"는 "크기 |S|인 빡빡한 집합이 모두 막혔다"와 같은 말이다. 문제는 증명이 이 가정을 **어느 집합들에** 실제로 쓰는가이다.

## 2. 증명에서 최대성이 쓰인 곳

| # | 위치 (`healing_proof.tex`) | 실제로 필요한 것 |
|---|---|---|
| U1 | 27행, 출발 집합 S | S가 막혔다 |
| U2 | 보조정리 stuck (46행) "By Lemma aug and maximality" | 해당 집합 T가 막혔다 (보조정리 aug만 씀) |
| U3 | 보조정리 exchange (72행) "it has maximum size, so Lemma stuck applies to T′" | 교환 결과 T′ = T − t + y가 막혔다 |
| U4 | 보조정리 exchange, K₄ 경우 (81행) "the same argument to y⁺" | T − t + y⁺가 막혔다 |
| U5 | 사슬 보조정리 (114행) z±의 S-이웃이 서로 다름 | S − t(z⁺) + z⁺가 막혔다 (보조정리 exchange (a)를 z⁺에 적용) |
| U6 | 사슬 보조정리 (117행) "contradicting Lemma exchange(a) at stage i" | T_i − t + y (y ∈ Y_i)가 막혔다 |
| U7 | 결론 (129행) 사슬을 한 단계 늘릴 수 있음 | T_j가 막혔다 |

표에 적지 않은 암묵적 쓰임(69, 76, 81, 107, 123행: "y의 다른 이웃은 Y 위", "T′ 성분 구조", 이웃 점 y^±에서의 교환, 사슬의 이웃 관계)도 같은 두 종류의 집합에 대한 것이다(검토 보고서 §1). 모든 쓰임이 **구체적으로 정해진 집합 하나**에 대한 것이다. 그 집합들은 전부 다음 꼴이다.

> 사슬의 각 단계 j에서, 현재 집합 T_j 자신과, T_j의 홀수 사이클 성분 Y_j의 한 점 y를 그 유일한 T_j-이웃 t와 바꾼 집합 T_j − t + y.

보조정리 exchange의 첫 부분(T′가 빡빡하다)은 T가 막혔다는 것(→ 보조정리 stuck → y의 T-이웃이 t 하나)만 쓰고 최대성은 쓰지 않는다.

## 3. 구성적 명제

**명제 (교환 사슬).** G가 최대 차수 3 이하의 연결 그래프이고 K₄가 아니라 하자. S가 막힌 빡빡한 집합이고 fr(G − S) ≥ 1이면, 다음 과정은 늦어도 c단계(c = G − S의 성분 수, 사슬 전체의 교환 확인은 n + c회 이하) 안에 **덧붙일 수 있는** 빡빡한 집합(크기 |S|)을 만난다.

- T_0 = S, Y_0 = G − S의 홀수 사이클 성분 하나.
- 단계 j: Y_j의 모든 점 y에 대해 T_j − t(y) + y를 만들어 덧붙일 수 있는지 본다. 하나라도 되면 멈춘다.
- 안 되면 w_j가 아닌 p_{j+1} ∈ Y_j를 골라 T_{j+1} = T_j − w_{j+1} + p_{j+1}(w_{j+1} = p_{j+1}의 T_j-이웃), Y_{j+1} = G − T_{j+1}에서 w_{j+1}을 포함한 성분으로 둔다.

**증명.** 과정이 멈추지 않는다고 하자. 그러면 U1–U7에 등장하는 모든 집합이 막혔으므로(단계마다 Y_j의 모든 점에서의 교환을 확인했고, T_j 자체는 그 앞 단계의 교환 결과다), `healing_proof.tex`의 보조정리 stuck, exchange, chain과 결론의 논증이 "최대 크기"를 "막힘"으로 바꿔 그대로 성립한다. 특히 (I2)에 의해 R_1, R_2, …는 G − S의 서로 다른 성분이므로 사슬은 c단계를 넘을 수 없는데, 결론의 논증은 사슬을 한 단계 더 늘릴 수 있음을 보인다. 모순이다. ∎

(주의: T_j 자체가 막혔다는 것은 앞 단계에서 확인했다. 단계 0에서는 S가 막혔다는 가정이다. U5의 z⁺는 Y_0 = Z의 점이므로 단계 0의 확인에 포함되고, U6의 y는 Y_i의 점이므로 단계 i의 확인에 포함된다.)

**따름정리 (알고리즘).** S = ∅에서 시작해 (1) 덧붙일 수 있으면 덧붙이고, (2) 막혔으면 위의 교환 사슬로 덧붙일 수 있는 같은 크기의 집합으로 옮긴 뒤 덧붙인다. 매 반복마다 |S|가 1 늘고, 빡빡한 집합의 크기는 fr을 넘지 않으므로 fr번 반복 뒤 fr(G − S) = 0이 된다. 한 번의 교환 사슬은 O(c·n)개의 집합을, 한 번의 덧붙이기 판정은 O(n)번의 fr 계산을 쓴다. 따라서 fr 계산을 다항 번 호출한다. 평면 그래프에서 fr은 최소 T-join으로 다항 시간이므로 전체가 다항 시간이다.

이것은 원고 논의 절의 열린 문제 (1)("구성적 판")에 대한 답이다. 다만 순수한 탐욕 알고리즘이 막히지 않는다는 더 강한 명제는 여전히 열려 있다.

## 4. 구현과 수치

- `constructive_heal.py`: 위 알고리즘. 교환 사슬 탐색은 증명이 요구하는 조건(Y_j의 점마다 T_j-이웃이 하나, 교환이 빡빡함, 사슬 길이 ≤ c + 1)을 모두 확인하고, 어기면 오류를 낸다.
- 무작위 이웃-3 그래프(8–18정점) 700개, 평면 격자 4개(깎은 펜로즈 N = 190, 270; Voronoi 거품 N = 78; 결함 벌집 N = 129): 모두 크기 fr의 독립 횡단을 만들었다.
- 이 무작위 시험에서는 교환 사슬 탐색이 호출되지 않았다. 그러나 12정점 평면 그래프 `K?`CPagPagEG`에서는 알고리즘이 실제로 막혀 교환 사슬을 호출했고, 교환 한 번으로 빠져나와 크기 fr = 4의 횡단을 만들었다.
- 검토 에이전트의 추가 시험(`reviews/constructive_*.py`): 12–18정점의 막힌 사례 전부가 단계 0에서 해결. 사슬을 실제로 전진시키는 막힌 사례 1492개(평면, 120정점 이하)를 만들어 시험: 사슬 전진은 최대 3번, c를 넘은 적 없음, 예외 0번.
- 실용적 의미: 격자 계산에서는 대부분 "Ising 바닥상태 → 좌절 끝점 하나 상태 3 → 다시 바닥상태" 반복만으로 충분하고, 드물게 막히면 교환 사슬이 해결한다. 기존 인증 알고리즘(바닥상태 하나 + 2-SAT)과 달리 **실패할 수 없는** 절차다.
- 검토 제안(강화판, 미반영): 보조정리 stuck의 걷기 논증과 교환 뒤 색칠을 직접 적으면, fr 오라클 없이 **최적 색칠 하나**만으로 다항 시간 구성이 된다. 막힘 판정도 오라클 없이 된다(막힘 ⇔ 좌절 있는 성분이 모두 홀수 사이클이고 모든 점에 S-이웃이 있음). 검토 에이전트가 구현·시험(`reviews/constructive_single_groundstate.py`, assert 실패 0).
