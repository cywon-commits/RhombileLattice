# 정리 A: D3 ≥ ⌊Δ/2⌋이면 색 3이 필요 없다 (다항 쪽)

상태: **정식 증명.** 수치 점검은 `verify_theorem_A.py`에 있다.

## 0. 설정과 기호

- G = (V, E)는 단순 그래프(고리·중복 간선 없음)이고, d(v)는 차수, Δ = max_v d(v)다.
- D3 ≥ 0은 실수이고, s : V → {1, 2, 3}는 3색 배정이다.

```
cost(s) = mono(s) + D3 · |s⁻¹(3)|,   mono(s) = #{vw ∈ E : s(v) = s(w)},
OPT(G, D3) = min_s cost(s).
```

- s(v) = 3인 정점 v에 대해 다음과 같이 둔다.
  - a(v) = #{w ∈ N(v) : s(w) = 3}
  - n₁(v), n₂(v) = 색 1, 2인 이웃의 수. 따라서 n₁ + n₂ + a = d(v)이다.
- 2색 좌절: fr(H) = min_{t : V(H) → {1,2}} mono(t) = |E(H)| − maxcut(H)
- S ⊆ V에 대해 e(S)는 S 내부 간선 수다.

## 1. 국소 재색칠 보조정리

**보조정리 A.1.** s(v) = 3이라 하자. c ∈ {1, 2}를 n_c(v) = min(n₁(v), n₂(v))가 되도록 고르고, s'를 v만 c로 바꾼 배정이라 하자. 그러면

```
cost(s') − cost(s) = min(n₁(v), n₂(v)) − a(v) − D3  ≤  ⌊(d(v) − a(v))/2⌋ − a(v) − D3  ≤  ⌊d(v)/2⌋ − D3.
```

*증명.* v에 닿지 않는 간선과 v가 아닌 정점의 항은 변하지 않는다. v에 닿는 간선 vw는 세 경우로 나뉜다.

- s(w) = 3이면 전에는 단색이었고 후에는 아니다. 이런 간선이 a(v)개이므로 −a(v)이다.
- s(w) = c이면 전에는 단색이 아니었고 후에는 단색이다. +n_c(v)이다.
- s(w)가 c도 3도 아니면 전후 모두 단색이 아니다. 변화 없음.

정점 항은 −D3이다. 이를 모두 더하면 첫 등식이 나온다.

부등식은 min(n₁, n₂) ≤ ⌊(n₁ + n₂)/2⌋ = ⌊(d − a)/2⌋ ≤ ⌊d/2⌋이고 a ≥ 0이라는 데서 나온다. ∎

## 2. 주정리

**정리 A.2 (정점별 형태).** W = {v ∈ V : ⌊d(v)/2⌋ ≤ D3}라 하자.

- **(a)** 모든 s에 대해 cost(s*) ≤ cost(s)이고 s*⁻¹(3) ∩ W = ∅인 s*가 있다. s*는 s에서 |s⁻¹(3) ∩ W|번 이하의 재색칠로 얻어진다.
- **(b)** ⌊d(v)/2⌋ < D3이면, 어떤 최적해에서도 s(v) ≠ 3이다.
- **(c)** 모든 최적해 s와 s(v) = 3인 모든 v에 대해 min(n₁(v), n₂(v)) ≥ a(v) + D3이다.

*증명.*

(a) s⁻¹(3) ∩ W가 비어 있지 않으면 그 안의 v 하나에 보조정리 A.1을 적용한다. 비용 변화는 ⌊d(v)/2⌋ − D3 ≤ 0 이하다. 새 색 3 정점은 생기지 않으므로 |s⁻¹(3) ∩ W|가 정확히 1 준다. 이 한계는 v의 차수에만 의존하고 다른 정점의 현재 색과는 무관하다. 따라서 반복할 수 있고 |W|번 안에 끝난다.

(b) s가 최적이고 s(v) = 3이면, A.1의 s'에 대해 cost(s') − cost(s) ≤ ⌊d(v)/2⌋ − D3 < 0이다. 최적성에 모순이다.

(c) 최적이면 cost(s') − cost(s) = min(n₁, n₂) − a − D3 ≥ 0이다. ∎

**따름정리 A.3 (Δ 형태).**

1. D3 ≥ ⌊Δ/2⌋이면 색 3을 쓰지 않는 최적해가 있고, OPT(G, D3) = fr(G) = |E| − maxcut(G)이다.
2. D3 > ⌊Δ/2⌋이면 **모든** 최적해가 색 3을 쓰지 않는다.

*증명.*

1. W = V이므로 A.2(a)를 최적해에 적용한다. 그 결과는 {1,2} 배정이고, {1,2} 배정의 비용은 mono ≥ fr(G)이다. 따라서 OPT = fr(G)이다.
2. A.2(b)에서 나온다. ∎

## 3. 알고리즘

**정리 A.4.** G가 평면이고 D3 ≥ ⌊Δ/2⌋이면, OPT(G, D3)와 최적 배정을 다항 시간에 구할 수 있다.

*증명.* 따름정리 A.3에 의해 평면 max-cut 하나를 풀면 된다. 평면 max-cut은 다항 시간이다(Hadlock 1975; Orlova–Dorfman 1972; Barahona 1982의 §3).

- 평면 그래프 G의 2색 배정에서 단색 간선의 집합은 쌍대 그래프 G*의 간선 집합 F로서, G*의 홀수 차수 꼭짓점 집합(= G의 홀수 면 집합) T에 대한 T-join이다.
- 역으로 모든 T-join은 어떤 2색 배정의 단색 간선 집합이다.
- 따라서 fr(G)는 G*의 최소 T-join 크기이고, 최소 가중 완전 매칭으로 다항 시간에 계산된다. ∎

주석: 이 논증에는 D3가 입력의 일부여도 상관없다. ⌊Δ/2⌋와 비교만 하면 되기 때문이다.

## 4. 최적해의 국소 구조 (A.2(c)의 결과)

**따름정리 A.5.** 모든 최적해 s와 s(v) = 3인 모든 v에 대해 다음이 성립한다.

- **(i) 독립성.** D3 > ⌊(Δ − 1)/2⌋ − 1이면 a(v) = 0이다. 즉 색 3 집합이 독립이다. 특히 **Δ ≤ 4이면 모든 D3 > 0에서** 독립이다.
- **(ii) 구간 구조.** k − 1 < D3 ≤ k (k ≥ 1 정수)이면 min(n₁, n₂) ≥ a + k이다. 따라서 d(v) ≥ 3a + 2k이다.
- **(iii) Δ = 4, 1 < D3 < 2이면** d(v) = 4, n₁ = n₂ = 2, a = 0이다.
- **(iv) Δ = 3, 0 < D3 < 1이면** d(v) = 3, a = 0, {n₁, n₂} = {1, 2}이다.

*증명.*

- (i) a ≥ 1이면 min(n₁, n₂) ≤ ⌊(Δ − a)/2⌋ ≤ ⌊(Δ − 1)/2⌋ < 1 + D3 ≤ a + D3이 되어 A.2(c)에 모순이다. Δ ≤ 4이면 ⌊(Δ−1)/2⌋ − 1 ≤ 0 < D3이다.
- (ii) min(n₁, n₂)는 정수이고 a + D3 이상이므로 ⌈a + D3⌉ = a + k 이상이다. d = n₁ + n₂ + a ≥ 2(a + k) + a이다.
- (iii) (i)에서 a = 0이고, (ii)에서 k = 2이므로 n₁, n₂ ≥ 2이다. d ≤ 4이므로 등호가 성립한다.
- (iv) (i)에서 a = 0이고, (ii)에서 k = 1이므로 n₁, n₂ ≥ 1이다. d ≤ 3이다. ∎

**재정식화 (정의에서 곧바로 나옴).** S = s⁻¹(3)이라 하면 색 3끼리의 간선만 S 안에서 단색이 되므로

```
OPT(G, D3) = min_{S ⊆ V} [ D3·|S| + e(S) + fr(G − S) ].
```

A.5(i)의 조건 아래에서는 S를 독립집합으로 제한해도 된다(e(S) = 0).

**주석 (D3에 대한 모양).** OPT(G, ·)는 기울기가 |s⁻¹(3)| ≥ 0인 일차함수들의 최솟값이다. 따라서 비감소 오목 조각별 선형 함수이고, 꺾이는 점에서 색 3의 개수가 바뀐다. D3 > ⌊Δ/2⌋이면 상수 fr(G)이다.

## 5. 빡빡함: 모든 Δ ≥ 3에서 문턱 ⌊Δ/2⌋는 개선할 수 없다

**명제 A.6.** Δ ≥ 3에 대해, 바퀴 W_Δ(중심 h와 길이 Δ인 테두리 사이클)는 최대 차수가 Δ인 평면 그래프다. 모든 D3 < ⌊Δ/2⌋에서 W_Δ의 **모든** 최적해는 색 3을 쓴다. D3 > ⌊Δ/2⌋이면 어떤 최적해도 쓰지 않는다.

*증명.* k = ⌊Δ/2⌋라 하자.

- **fr(W_Δ) = ⌈Δ/2⌉.**
  - 하한: 삼각형 h r_i r_{i+1}이 Δ개 있다. 각 삼각형은 2색 배정에서 단색 간선을 적어도 하나 가진다. 바퀴살은 두 삼각형에, 테두리 간선은 한 삼각형에 들어가므로 Σ_T mono(T) ≤ 2·mono이다. 따라서 mono ≥ ⌈Δ/2⌉이다.
  - 상한: h = 1로 두고 테두리를 2, 1, 2, 1, …로 칠한다. Δ가 짝수이면 테두리의 1이 k개로 비용 k이다. Δ가 홀수이면 테두리의 1이 k개이고 테두리 단색 간선이 하나라서 비용 k + 1이다. 어느 쪽이든 ⌈Δ/2⌉이다.
- **중심을 색 3으로 하면** 비용은 D3 + fr(C_Δ)이다. 이는 Δ가 짝수이면 D3, 홀수이면 D3 + 1이다.
- 두 경우 모두 D3 + (⌈Δ/2⌉ − k) < ⌈Δ/2⌉ ⇔ D3 < k이다.
- 따라서 D3 < k이면 OPT < fr(W_Δ)이고, 색 3을 쓰지 않는 배정은 모두 비용이 fr(W_Δ) 이상이다. 그러므로 모든 최적해는 색 3을 쓴다.
- D3 > k인 경우는 따름정리 A.3.2에서 나온다. ∎

**다른 빡빡함 예시.**

- 정팔면체(Δ = 4): 2색 최소는 4이고, 진짜 3색칠(색 3이 대척점 쌍)은 비용 2·D3이다.
- 3 | L인 L×L 삼각 격자 토러스(Δ = 6, N개 사이트, 3N개 간선): 삼각형이 2N개이고 각 간선이 두 삼각형에 들어간다. 그래서 A.6과 같은 논증으로 fr ≥ N이고, Wannier 배치가 N을 달성한다. 진짜 3색칠의 비용은 (N/3)·D3이다. 따라서 D3 < 3이면 모든 최적해가 색 3을 쓴다. 프로젝트의 수치 결과 D3* = 3과 일치한다.
- 이 예시들에서 D3 = ⌊Δ/2⌋의 전이는 색 3을 쓰는 해와 2색 해의 **준위 교차**다.

## 6. 참고

- 정리 A는 평면성을 A.4(알고리즘)에서만 쓴다. A.1–A.3, A.5는 모든 단순 그래프에서 성립한다.
- 정수 D3는 퇴화점이다. D3 = ⌊d(v)/2⌋인 정점은 색 3을 쓰는 최적해와 쓰지 않는 최적해가 공존할 수 있다(A.2(a)는 "있다", (b)는 엄격한 부등식).
